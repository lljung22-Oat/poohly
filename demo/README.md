# เดโม PMS — คณะสังคมศาสตร์และมนุษยศาสตร์

เลือกโหมดที่หน้าแรก แล้วเข้า **หน้าหลักระบบงาน (Dashboard)** 7 การ์ด

ปีงบประมาณเริ่มต้น **2570** เลือก **2569** ได้

## สองระบบ PA ที่ไม่ปนกัน

| การ์ด | เอกสาร | ใครใช้ |
| --- | --- | --- |
| PA ประเมินภาระงาน | ชุด PA บุคคลากร แบบ 05–11 + IDP ผู้ปฏิบัติ/ผู้อนุมัติ | โหมดสายสนับสนุน |
| PA ภาระงานอาจารย์ | ประกาศค่าน้ำหนัก · คู่มือหลักเกณฑ์ · แบบ SHPA | โหมดอาจารย์ |

การ์ดของอีกสายจะจางและเปิดไม่ได้
