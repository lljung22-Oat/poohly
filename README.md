## สิ่งที่โปรแกรมทำแล้ว และสิ่งที่หยุดเพราะไม่มีต้นฉบับ

ทำแล้วในแกน Cursor: แยกสาย แยกบทบาท สี่ภาระงานตาม PMS สมรรถนะ 7 ข้อ สูตร UM-01 ล็อกหลังส่ง การไม่เห็นด้วยที่พา PA กับ CC กลับหัวหน้างานคู่กัน IDP แบบข้อความ 70/20/10 แบบโครงการวิจัยสองชีต และบัญชีตัวชี้วัดปี 2570 แบบอ่านอย่างเดียว

ยังไม่คิดเอง

- ตารางคะแนนบทความและคอลัมน์ SHPA = `SOURCE_MISSING` จึงไม่คิดหน่วยรายคนจากฐาน 1,820
- แบบ 05 ถึง 09 และ rubrics สายสนับสนุน = `SOURCE_MISSING`
- แบบคำมั่น 11 ไม่มีเมนู
- วันในปฏิทินและประเภทบุคคลที่กำหนดจำนวนรอบ = `SOURCE_MISSING`
- ไม่มีสูตรแปลงคะแนนตนเอง 0–10 เป็น `paScore` จึงไม่แสดงระดับรวม
- ตัวหาร 4.12 และสูตรร้อยละ 4.4 คงเป็น `SOURCE_MISSING`
- ไม่นำแถวตัวอย่างสังกัดศึกษาศาสตร์มาเป็นข้อมูลเดโม
