# วงจรและเงื่อนไข — รวมจากคู่มือและคำแนะนำระบบ

คัดเฉพาะที่เอกสารเขียน รายละเอียดยาวอยู่ที่ `docs/pa-manuals-digest.md`

## กระบวนการทั้งรอบ (สไลด์ infographic PMS)

1. จัดทำ PA — ผู้ปฏิบัติงานกับผู้บังคับบัญชาขั้นต้น
2. รายงานผลการดำเนินงาน และประเมินตนเอง
3. ประเมินผล PA + Competency — ผู้บังคับบัญชาขั้นต้นเป็นผู้ประเมิน
4. คณะกรรมการประเมินพิจารณารับรอง จัดกลุ่มคะแนน (ในสไลด์มีขั้นนี้)
5. หัวหน้าส่วนงาน/หัวหน้าหน่วยงานลงนามรับผล
6. แจ้งผล + Feedback
7. ผู้ปฏิบัติงานรับทราบ
8. จากนั้นจัดทำ IDP

ระหว่างรอบ: ผู้บังคับบัญชาขั้นต้นติดตามความคืบหน้าตาม PA (แบบ 06 ในชุดบุคคลากร)

## จังหวะจัดทำข้อตกลง (UM-03 + PMS)

ผู้รับการประเมินยืนยันประวัติส่วนตัวก่อนกรอก  
โครงสร้าง PMS ต่อภารกิจ: ภาระงาน → ข้อตกลง → ตัวชี้วัด → เป้าหมาย  
สี่ภาระงานตามข้อความบนจอ PMS:

1. งานตามภารกิจที่สอดคล้องกับประเด็นยุทธศาสตร์ของมหาวิทยาลัยและแผนกลยุทธ์ของส่วนงาน
2. งานตามภารกิจหลักของตำแหน่งงาน ตามหน้าที่ความรับผิดชอบ ตามคำบรรยายลักษณะงาน
3. งานตามภารกิจที่ได้รับมอบหมาย
4. งานตามภารกิจเพื่อส่วนรวม

ตัวชี้วัดติ๊กได้: ปริมาณ / คุณภาพ / เวลา / ความคุ้มค่า / ความพึงพอใจ  
น้ำหนักตัวชี้วัดในแต่ละข้อตกลงรวม 100  
น้ำหนักภาระงานทั้งฉบับรวม 100  
เกณฑ์ 5 ช่วงคะแนน  
บันทึกฉบับร่างได้  
ส่งขออนุมัติแล้วหัวหน้างานอนุมัติทีละข้อหรือทั้งหมด หรือไม่อนุมัติพร้อมเหตุผล  
หลังเห็นชอบ UM-03 ยังมีจังหวะเพิ่มเติม/แก้ไข/ยกเลิกได้ มี dialog กันกดพลาด

สายอาจารย์ใช้ตาราง SHPA / ประกาศค่าน้ำหนัก **ซ้อนบนสี่ภาระงานเดียวกัน** ไม่สร้างภาระงานที่ 5

บัญชีตัวชี้วัดจาก `คำอธิบายตัวชี้วัด PA 2570 (ฉบับจัดทำ PA).pdf` เจ้าของงานใช้ฝั่งอาจารย์  
ปกเล่มยังเขียนว่าข้อตกลงส่วนงาน เก็บทั้งคู่  
ภาระงานข้อ 1 อ้างอิงชื่อตัวชี้วัดได้ แต่ห้ามย้ายสูตร SciVal ตัวหาร 79/248/26 ไปคิดหน่วยรายคน

แบบติดตามข้อมูลโครงการวิจัย ปี 2570 เป็นเงื่อนไขฝั่งอาจารย์ มีสองชีต `iNT` และ `แจ้งทำวิจัย`  
ไม่ใช่จังหวะแบบ 06 ของสายสนับสนุน และไม่ใช่การล็อกหลังส่งรายงานผล PA

ตัวชี้วัดผลงานตีพิมพ์ที่จัดทำ PA กับส่วนงานตามเล่มคือ 1.1 Q1, 1.2 Top10, 1.3 ร่วมภาคเอกชน  
Number of International Publications ทั้งก้อนเป็นตัวชี้วัดที่ **ไม่จัดทำ PA กับส่วนงาน**  
เงินทุน 1.9.1–1.9.3 นับเงินในสัญญารับทุน รายงานเบิกจ่ายจริงได้แต่ไม่นับใน PA ส่วนงาน  
นักศึกษาแลกเปลี่ยน 2.16.1–2.16.4 เก็บปีการศึกษา 2569 และนับ Physical Mobility เท่านั้น  
3.2 ใช้มติคณะกรรมการ Changemaker/Change Agent เป็นที่สุด  
4.4 ความถี่ในเล่มเขียนทั้งปีละครั้งและรายไตรมาส เก็บทั้งคู่  
4.12 ตัวหารยังไม่มีในเล่ม = `SOURCE_MISSING`

## จังหวะประเมินผลงาน

เจ้าของงานสั่งบนเดโม: ผลการดำเนินงาน **ไม่ต้องมีรายงานยาว** มีตัวเลขกับประเมินตนเอง  
ในสไลด์ PMS กล่องรายงานผลยังมีคำอธิบายและไฟล์แนบ — เก็บความสามารถแนบหลักฐานไว้ในข้อตกลง/หลักฐาน อย่าบังคับ textarea รายงานในหน้าประเมินผลงาน

คะแนนตนเอง 0–10  
ส่งแล้วแก้ไม่ได้ (สไลด์ตัวโต)

ตัวอย่างเกณฑ์ในสไลด์ PMS (ใช้เมื่อต้นฉบับแบบ 04/ประกาศไม่กำหนดเป็นอย่างอื่น):

- 9–10 สูงกว่าเป้าหมาย
- 7–8 ตามเป้าหมาย
- 5–6 ใกล้เคียง
- 3–4 ต่ำกว่า
- 0–2 ต่ำกว่ามาก

Rubrics สายสนับสนุนอ่านจากไฟล์ 04 เมื่อมีไฟล์ ไม่ใช้ตัวอย่าง PMS ไปทับถ้าไฟล์ 04 เขียนต่าง

## จังหวะสมรรถนะ (UM-01 + PMS2)

ผู้ประเมินให้คะแนนพฤติกรรมย่อย 0–10  
สูตรรายการใน UM-01: `C = B / (A × 10) × 100`  
สูตรประเภทเทียบสัดส่วน: `D = A × C / B`  
ยืนยันส่งผลเมื่อครบทุกประเภทที่เปิดให้คนนั้น แล้วแก้ไม่ได้  
ยกเลิกประเมินตนเองไม่ได้  

CC 7 ข้อคงที่ของมหาวิทยาลัย (Mastery Altruism Harmony Integrity Determination Originality Leadership)  
FC ตามตำแหน่งและอายุงาน  
MC เฉพาะผู้บริหาร  

ใน PMS ตัวอย่างสรุป: PA 80 + CC 20 = 100  
ระดับในภาพ: ดีเด่น 90–100 / ดีมาก 80–89.99 / ดี 70–79.99 / พอใช้ 60–69.99 / ควรปรับปรุง ต่ำกว่า 60  

หัวหน้างานขั้นต้นให้คะแนนแล้วส่งหัวหน้างาน  
หัวหน้างานกดตรวจสอบคะแนนเมื่อ PA และ CC ครบทั้งคู่ มีช่องจุดเด่น ข้อควรพัฒนา ข้อเสนอแนะของผู้บังคับบัญชาขั้นต้น

รับทราบ PA หรือ CC ครั้งเดียวถือว่าทั้งคู่  
ไม่เห็นด้วยต้องมีเหตุผล

## จังหวะ IDP

พัฒนาประมาณ 1–2 รายการต่อปี (คำบนจอ PMS ใช้คำว่าไม่ควรเกิน)  
วิธี 70 / 20 / 10  
งบประมาณไม่มีใส่ 0  
หัวหน้างานอนุมัติเหมือน PA  
รายงานการพัฒนาแล้วแก้ไม่ได้  
ผลเป็นข้อความ เป็นไปตามที่คาดหวัง หรือ ไม่เป็นไปตามที่คาดหวัง ไม่ใช่คะแนน 0–10  
รับทราบหรือไม่เห็นด้วยได้

ชุดบุคคลากรแยกคู่มือ IDP ผู้ปฏิบัติ กับ IDP ผู้อนุมัติ (ไฟล์ 10 สองฉบับ)
