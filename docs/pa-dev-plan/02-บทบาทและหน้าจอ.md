## ชุดประเมินต่อคน (จาก PMS ห้ามยัดทุกแบบให้ทุกคน)

แถวที่มีเมื่อตำแหน่งกำหนดไว้เท่านั้น

- PA ทุกคนที่ต้องประเมินผลการปฏิบัติงาน
- CC ทุกคน (7 ข้อคงที่ของมหาวิทยาลัย)
- IDP ทุกคนหลังวงจร PA ตามสไลด์
- FC เมื่อมีสมรรถนะตามสายอาชีพของตำแหน่งและช่วงอายุงาน
- MC เมื่อเป็นผู้ดำรงตำแหน่งบริหาร ช่องดำทึบใน UM-01 = ไม่ต้องประเมินประเภทนั้น

Admin ส่วนงานมีหน้าที่ตรวจว่าชุดของแต่ละคนครบตามตำแหน่ง **ไม่ใช่หน้าที่ผู้รับการประเมินเลือกเอง**

## สถานะที่สไลด์ PMS เขียน (วงกลมบนฟอร์ม)

1. พนักงานประเมินตนเอง
2. หัวหน้างานขั้นต้น (ในสไลด์: กรรมการประเมิน)
3. หัวหน้างาน (ในสไลด์: ประธานกรรมการประเมิน)
4. คณะติดลงนาม
5. พนักงานรับทราบประเมินผล
6. เสร็จสิ้น

กรณีไม่เห็นด้วยมีแถบเหตุผล แล้วสถานะ PA และ CC **คู่กัน** กลับไปที่หัวหน้างาน ถ้ากดไม่เห็นด้วยจากแบบ PA หรือ CC  
FC / MC ไม่เห็นด้วยแยกแบบ ตาม PMS2
