## ชีตในไฟล์ (สองชีต ห้ามรวมเป็นตารางเดียว)

### ชีต `iNT`

หัวคอลัมน์ตามแถว 1 เรียงซ้ายไปขวา

| ลำดับ | ชื่อคอลัมน์ตามไฟล์ |
| --- | --- |
| 1 | สถานะ |
| 2 | ที่ |
| 3 | ชื่อโครงการ |
| 4 | หัวหน้าโครงการ |
| 5 | สังกัด |
| 6 | ชื่อแหล่งทุน |
| 7 | ระยะเวลาเริ่มโครงการ |
| 8 | ระยะเวลาสิ้นสุดโครงการ |
| 9 | จำนวนเงินตลอดโครงการ |
| 10 | วัตถุประสงค์ |
| 11 | ประโยชน์ของโครงการ |
| 12 | ผลผลิต (output) |
| 13 | สัญญาเลขที่ |

ค่าสถานะที่ปรากฏในไฟล์มีคำเดียว: `รออนุมัติดำเนินโครงการ`  
สถานะอื่นยังไม่มีในไฟล์ = `SOURCE_MISSING` ห้ามสร้างรายการรออนุมัติ/อนุมัติ/ปิดโครงการเอง

ในตัวอย่างแถว 3 คอลัมน์ระยะเวลาเริ่มเป็นข้อความ `210 วัน` และไม่มีค่าสิ้นสุด วัตถุประสงค์ ประโยชน์ ผลผลิต สัญญาเลขที่  
อย่าบังคับว่าทุกคอลัมน์ต้องมีค่า

จำนวนเงินในตัวอย่างเป็นตัวเลข (2800000 และ 7190000) ไม่มีหน่วยเขียนในหัวคอลัมน์ ห้ามเติมคำว่าบาทถ้าจะแสดงให้ตรงหัวตาราง ถ้าจะเชื่อมกับตัวชี้วัด 1.9 ที่หน่วยเป็นบาท ต้องรอประกาศหรือคำสั่งเพิ่ม ห้ามคิดเองในรอบนี้

### ชีต `แจ้งทำวิจัย`

หัวคอลัมน์ตามแถว 1

| ลำดับ | ชื่อคอลัมน์ตามไฟล์ |
| --- | --- |
| 1 | ที่ |
| 2 | ชื่อโครงการ |
| 3 | หัวหน้าโครงการ |
| 4 | สังกัด |
| 5 | หมายเหตุ |

ค่าหมายเหตุที่ปรากฏในไฟล์มีคำเดียว: `ทุนส่วนตัว`  
หมายเหตุอื่นยังไม่มี = `SOURCE_MISSING`

ชีตนี้ไม่มีคอลัมน์เงิน แหล่งทุน สัญญา ระยะเวลา อย่าไปยืมคอลัมน์จากชีต `iNT`

## สิ่งที่ไฟล์นี้ไม่มี — ห้ามเติม

- สูตรคิดหน่วยจากจำนวนเงิน
- การนับ `ทุนส่วนตัว` เข้าตัวชี้วัด 1.9.1 1.9.2 1.9.3 (เล่มตัวชี้วัดพูดถึงแหล่งทุนภายนอกและ CTA ไม่ได้พูดถึงทุนส่วนตัว)
- รายการสถานะครบวงจร
- การบังคับว่าหัวหน้าโครงการต้องเป็นผู้รับการประเมินคนเดียว (ตัวอย่างชีต `iNT` แถว 1 มีหลายชื่อในช่องเดียวกัน คั่นบรรทัด)
- ข้อมูลตัวอย่างในไฟล์เป็นสังกัดศึกษาศาสตร์ ห้ามนำไปแทน `facultyName` ของคณะสังคมศาสตร์และมนุษยศาสตร์ และห้ามใส่ชื่อในตัวอย่างเป็นบัญชีเดโม

## ความสัมพันธ์กับเล่มตัวชี้วัด 2570 (เท่าที่ชื่อคอลัมน์ชนกัน ไม่ขยาย)

ชื่อคอลัมน์ `ชื่อแหล่งทุน` `จำนวนเงินตลอดโครงการ` `สัญญาเลขที่` ตรงทิศกับคำในเล่มเรื่องรายงานเงินในสัญญารับทุนของ 1.9.1–1.9.3  
ยัง **ห้ามเขียนสูตรเชื่อม** จนกว่าจะมีประกาศหรือแบบ SHPA ต้นฉบับบอกว่าช่องไหนคิดหน่วยเท่าไร

เล่มขอให้รายงานเบิกจ่ายจริงเพิ่มด้วยแต่ไม่นับใน PA ส่วนงาน — ใน Excel นี้ **ไม่มีคอลัมน์เบิกจ่ายจริง** อย่าเพิ่มช่องนั้น
