# คู่มือสำหรับผู้เขียนระบบประเมินผลการปฏิบัติงาน

ส่วนงาน: คณะสังคมศาสตร์และมนุษยศาสตร์ มหาวิทยาลัยมหิดล  
ใช้ประกอบการจัดทำระบบตามคู่มือการประเมินสมรรถนะออนไลน์ (MUIT-APP-MUHR-PA-UM-01) คู่มือการจัดทำข้อตกลงการปฏิบัติงานออนไลน์ (MUIT-APP-MUHR-PA-UM-03) และคำแนะนำระบบบริหารผลการปฏิบัติงาน

## 1. ขอบเขตการเขียน

ผู้เขียนระบบจัดทำส่วนติดต่อผู้ใช้ ส่วนบริการ และฐานข้อมูลให้ตรงเอกสารต้นฉบับ  
ห้ามกำหนดเกณฑ์ ค่าน้ำหนัก ระดับคะแนน หรือช่องข้อมูลที่ไม่มีในประกาศ คู่มือ หรือแบบพิมพ์  
ถ้าเอกสารต้นทางยังไม่ครบ ให้ระบุว่ายังไม่มีแหล่งที่มา แล้วระงับการเติมค่านั้น

## 2. องค์ประกอบที่กำหนดให้จัดทำ

1. ส่วนติดต่อผู้ใช้ด้วย React ร่วมกับ HTML CSS และ Tailwind CSS สำหรับแสดงผล จัดการสถานะบนจอ และเรียกบริการ
2. ส่วนบริการด้วย Node.js (Express) สำหรับบริการแบบ REST และหรือ GraphQL ตรรกะธุรกิจ และการพิสูจน์ตัวตนด้วยบัตรโทเคน JWT
3. ฐานข้อมูล MySQL สำหรับโครงสร้างข้อมูลและการบันทึก แก้ไข ลบ เรียกดู

ทางเลือกส่วนบริการ Python (FastAPI) และ C# (.NET) มีในบัญชีเอกสารเท่านั้น มิให้จัดทำขนานกับ Express

เมื่อกระจายงานให้โปรแกรมคุยอื่น ให้ส่งซองละหนึ่งเรื่อง ตามรายการไฟล์ใน `PA/dev-plan/08-รายการส่งไฟล์ต่อซอง.md` ห้ามส่งประกาศหน่วยหรือแบบ SHPA ให้ซองข้อความ และห้ามเปิดซองแบบพิมพ์ 05 ถึง 09 ถ้าต้นฉบับยังไม่อยู่ในเครื่อง

## 3. ชุดเอกสารที่ต้องยึด

### 3.1 บุคลากรสายสนับสนุนและแบบพิมพ์บุคคลากร

หนังสือแจ้งการประเมินผลการปฏิบัติงาน กระบวนการประเมิน ขั้นตอนการเข้าใช้งานระบบประเมินออนไลน์ หลักเกณฑ์ประเมินสายสนับสนุน แบบข้อตกลงและประเมินผลการปฏิบัติงาน แบบติดตามผลการปฏิบัติงาน แบบรายงานผลการปฏิบัติงาน แบบสรุปและแจ้งผลการประเมิน แบบสรุปคะแนนผลการประเมิน ขั้นตอนการใช้ระบบแผนพัฒนารายบุคคลของผู้ปฏิบัติและของผู้อนุมัติ  
แบบคำมั่นมีในชุดเอกสาร มิให้เปิดเป็นรายการหลักจนกว่าผู้มีอำนาจสั่งคืน

### 3.2 สายวิชาการ

คู่มือคำอธิบายหลักเกณฑ์ ประกาศหลักเกณฑ์ค่าน้ำหนักและการจัดทำข้อตกลง แบบฟอร์ม SHPA  
ค่าหน่วยและเพดานกลุ่มใช้ตามประกาศของส่วนงาน มิใช่ตารางของสายสนับสนุน

### 3.3 ระบบออนไลน์ของมหาวิทยาลัย

การประเมินสมรรถนะออนไลน์สำหรับผู้ประเมิน การจัดทำข้อตกลงการปฏิบัติงานออนไลน์สำหรับผู้รับการประเมิน และคำแนะนำระบบบริหารผลการปฏิบัติงาน

### 3.4 ตัวชี้วัด PA ส่วนงานปีงบประมาณ 2570

คำอธิบายตัวชี้วัดตามแผนยุทธศาสตร์มหาวิทยาลัย ปีงบประมาณ 2570  
ปกเล่มเขียนว่าข้อตกลงของส่วนงาน ผู้มีอำนาจสั่งให้ใช้ฝั่งอาจารย์  
แบบติดตามข้อมูลโครงการวิจัย ปี 2570 เป็นแบบเพิ่มของฝั่งอาจารย์ มีสองแผ่นงาน `iNT` และ `แจ้งทำวิจัย` มิใช่แบบติดตามของสายสนับสนุน  
มิให้รวมสูตรตัวหารระดับมหาวิทยาลัยเข้าตารางหน่วย และมิให้นับทุนส่วนตัวเข้าตัวชี้วัดเงินทุนภายนอกถ้าต้นฉบับไม่ได้เขียน  
รายการอยู่ในแฟ้มกำหนดค่า `unitPaFy2570` และ `facultyResearchTracking2570`

## 4. บทบาทในระบบ มิให้ปะปนหน้าจอ

| บทบาท | หน้าที่ที่จัดทำหน้าจอให้ |
| --- | --- |
| ผู้รับการประเมิน สายวิชาการ | ข้อตกลงตามประกาศและแบบ SHPA ประเมินตนเอง สมรรถนะ แผนพัฒนารายบุคคล รับทราบผลของตนเอง |
| ผู้รับการประเมิน สายสนับสนุน | แบบข้อตกลง แบบติดตาม แบบประเมินผลงาน แบบสรุปและแจ้งผล ตามแบบพิมพ์บุคคลากร |
| หัวหน้างานขั้นต้น | ให้คะแนนผู้รับการประเมินในความดูแล แล้วส่งหัวหน้างาน |
| หัวหน้างาน | อนุมัติหรือส่งกลับข้อตกลง ให้คะแนน ส่งคะแนน อนุมัติและประเมินแผนพัฒนารายบุคคล |
| ฝ่ายบุคคลากรของส่วนงาน | เปิดรอบ กำหนดปฏิทิน ตรวจชุดประเมิน นำเข้าผู้ประเมิน มิให้คะแนนแทน |
| ผู้ดูแลระบบมหาวิทยาลัย | โครงสร้างส่วนงาน บัญชี และสิทธิ์ มิกรอกข้อตกลงแทนผู้รับการประเมิน |

ผู้รับการประเมินสายวิชาการมิเห็นแบบพิมพ์สายสนับสนุน  
ผู้รับการประเมินสายสนับสนุนมิเห็นตารางหน่วยตามประกาศสายวิชาการ

## 5. วงจรที่ต้องมีตามคำแนะนำระบบ

1. จัดทำข้อตกลงการปฏิบัติงาน
2. ประเมินผลงาน โดยผลการดำเนินงานเป็นตัวเลขและการประเมินตนเอง
3. ประเมินผลงานและประเมินสมรรถนะ
4. แจ้งผลและรับทราบผลการประเมินการปฏิบัติงาน
5. จัดทำแผนพัฒนารายบุคคล
6. รายงานผลการพัฒนารายบุคคล
7. ประเมินผลการพัฒนารายบุคคล เป็นไปตามที่คาดหวัง หรือไม่เป็นไปตามที่คาดหวัง
8. แจ้งผลและรับทราบผลการพัฒนารายบุคคล
9. รายงานและติดตามผลการดำเนินการ

น้ำหนักข้อตกลงทั้งฉบับเท่ากับหนึ่งร้อย ตามคู่มือการจัดทำข้อตกลง  
สมรรถนะหลักมีเจ็ดรายการตามชุดมหาวิทยาลัย  
สัดส่วนสรุปตามตัวอย่างในคำแนะนำระบบ คือผลการปฏิบัติงานแปดสิบและสมรรถนะหลักยี่สิบ หากส่วนงานมิได้ประกาศเป็นอย่างอื่น

## 6. สูตรที่อนุญาตให้เขียนในแกนระบบ

- หน่วยภาระงานสายวิชาการตามประกาศค่าน้ำหนัก
- คะแนนสมรรถนะตามคู่มือผู้ประเมิน `C = B / (A × 10) × 100` และสูตรประเภทตามสัดส่วนในเล่มเดียวกัน
- รวมผลการประเมินตามสัดส่วนแปดสิบกับยี่สิบเมื่อใช้ตัวอย่างของระบบบริหารผลการปฏิบัติงาน

นอกนั้นเป็นข้อความ ไฟล์แนบ และรายการเลือกจากต้นฉบับ

## 7. การพิสูจน์ตัวตนและสิทธิ์

เข้าสู่ระบบด้วยบัญชีอินเทอร์เน็ตของมหาวิทยาลัยตามรูปแบบที่คู่มือกำหนด  
ส่วนบริการออกบัตรโทเคน JWT และเปิดหน้าที่ตรงบทบาทเท่านั้น  
ห้ามมีรายการสลับบทบาทบนหน้าผู้รับการประเมิน
