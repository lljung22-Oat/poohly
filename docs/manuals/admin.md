# คู่มือสำหรับผู้ดูแลระบบประเมินผลการปฏิบัติงาน

ส่วนงาน: คณะสังคมศาสตร์และมนุษยศาสตร์ มหาวิทยาลัยมหิดล  
จัดทำตามหน้าที่ผู้ดูแลระบบส่วนงานและผู้ดูแลระบบมหาวิทยาลัยในคำแนะนำระบบบริหารผลการปฏิบัติงาน และตามคู่มือการจัดทำข้อตกลงการปฏิบัติงานออนไลน์

## 1. ผู้มีหน้าที่

### ผู้ดูแลระบบมหาวิทยาลัย

- นำเข้าโครงสร้างส่วนงาน ข้อมูลบุคลากร ผู้บังคับบัญชา และผู้ดำรงตำแหน่งบริหาร
- กำหนดบัญชีและสิทธิ์ผู้ประเมิน
- ให้คำปรึกษาการใช้ระบบในภาพรวม
- มิให้คะแนนและมิกรอกข้อตกลงการปฏิบัติงานแทนผู้รับการประเมิน

### ฝ่ายบุคคลากรของส่วนงาน (ผู้ดูแลระบบส่วนงาน)

- จัดทำรอบประเมินและปฏิทินการดำเนินงานของส่วนงาน
- ตรวจข้อมูลบุคลากรให้ครบในแต่ละรอบ
- ตรวจชุดประเมินให้ครบตามตำแหน่งของแต่ละคน ได้แก่ ข้อตกลงการปฏิบัติงาน แผนพัฒนารายบุคคล สมรรถนะหลัก สมรรถนะตามสายอาชีพ และสมรรถนะทางการบริหารเมื่อเป็นผู้บริหาร
- นำเข้าผู้ประเมิน
- ติดตามให้แล้วเสร็จตามปฏิทิน
- มิให้คะแนนแทนผู้ประเมิน

## 2. การเปิดรอบประเมิน

ระบุปีงบประมาณก่อนเข้าใช้งาน ตามคู่มือระบบออนไลน์  
ข้าราชการและลูกจ้างประเมินสองรอบต่อปี พนักงานมหาวิทยาลัยและพนักงานสมทบประเมินหนึ่งรอบต่อปี ตามชื่อรอบในระบบบริหารผลการปฏิบัติงาน  
ปีงบประมาณที่ส่วนงานนี้กำหนดใช้ คือ พ.ศ. 2569 และ พ.ศ. 2570

คำอธิบายตัวชี้วัด PA ปี 2570 และแบบติดตามข้อมูลโครงการวิจัย ปี 2570 ผู้มีอำนาจระบุว่าเป็นของฝั่งอาจารย์  
มิให้นำตัวหารระดับมหาวิทยาลัยเข้าสูตรหน่วย และมิเปิดแบบโครงการวิจัยในสายสนับสนุน

ปฏิทินแสดงกิจกรรม วันที่เริ่มต้น และวันที่สิ้นสุด ของส่วนงาน ลำดับกิจกรรมอ่านจากหนังสือและกระบวนการประเมินของส่วนงาน หากแฟ้มต้นทางยังไม่ครบ มิให้กำหนดวันเอง

## 3. ชุดประเมินรายบุคคล

แต่ละคนมีหลายแบบประเมิน มิใช่แบบเดียว

| แบบประเมิน | ผู้ที่ต้องมี |
| --- | --- |
| ข้อตกลงการปฏิบัติงาน | ผู้ที่ต้องรับการประเมินผลการปฏิบัติงาน |
| สมรรถนะหลัก | ทุกคนตามชุดมหาวิทยาลัยเจ็ดรายการ |
| แผนพัฒนารายบุคคล | ตามวงจรหลังแจ้งผลและรับทราบ |
| สมรรถนะตามสายอาชีพ | เมื่อตำแหน่งและช่วงอายุงานกำหนดไว้ |
| สมรรถนะทางการบริหาร | เมื่อดำรงตำแหน่งบริหาร หากระบบทำเครื่องหมายว่าไม่ต้องประเมินประเภทนั้น ให้คงตามนั้น |

ผู้รับการประเมินมิได้เป็นผู้เลือกชุดเอง ผู้ดูแลระบบส่วนงานเป็นผู้ตรวจความครบ

## 4. สิทธิ์เข้าสู่ระบบ

- ผู้รับการประเมินเข้าช่องทางบุคลากรหรืออาจารย์
- ผู้ประเมินเข้าช่องทางผู้ประเมินที่ได้รับสิทธิ์แล้ว
- ผู้ดูแลระบบเข้าช่องทางผู้ดูแลระบบ

ห้ามแสดงรายชื่อบัญชีผู้ประเมินในหน้าเข้าสู่ระบบทั่วไป  
การพิสูจน์ตัวตนใช้บัญชีอินเทอร์เน็ตของมหาวิทยาลัย และบัตรโทเคนที่ส่วนบริการออกให้

## 5. สิ่งที่ผู้ดูแลระบบส่วนงานติดตามได้

- สถานะข้อตกลงการปฏิบัติงาน
- สถานะการประเมินสมรรถนะ
- สถานะแผนพัฒนารายบุคคล
- รายงานและติดตามผลการดำเนินการตามรายการในคำแนะนำระบบ

ผู้ดูแลระบบส่วนงานเห็นภาพรวมตามปฏิทิน มิเข้าไปให้คะแนนในช่องของผู้ประเมิน

## 6. ข้อห้าม

- ห้ามรวมชุดประเมินสายวิชาการกับสายสนับสนุนเป็นชุดเดียว
- ห้ามเปิดแบบคำมั่นเป็นรายการหลักจนกว่าผู้มีอำนาจสั่ง
- ห้ามเพิ่มช่องข้อมูลที่ไม่มีในแบบพิมพ์หรือคู่มือ
- ห้ามเปลี่ยนสัดส่วนและระดับคะแนนที่ไม่มีในต้นฉบับ
