https://mypms.mahidol.ac.th/

เว็บสมัยใหม่ เมนูซ้าย KPI, ชุดประเมิน PA / CC / IDP / FC / MC

คำแนะนำ PMS1 + PMS2 เป็นสไลด์ชุดเดียวกัน

ภาพจาก PMS1: วงจรทั้งปี จัดทำ PA → รายงานผล → ประเมิน PA+สมรรถนะ → คณะกรรมการ → ลงนาม → แจ้งผล → รับทราบ → แล้วค่อยทำ IDP

วงจรการทำงานทั้งระบบ

  1. ยืนยันประวัติส่วนตัว แล้วจัดทำข้อตกลง (น้ำหนัก 100 + เกณฑ์ 5 ระดับ)
  2. หัวหน้าอนุมัติ หรือส่งกลับแก้ พร้อมเหตุผล
  3. ปลายรอบรายงานผล แนบหลักฐาน ประเมินตนเอง — ส่งแล้วแก้ไม่ได้
  4. กรรมการให้ความเห็น ประธานให้คะแนน (ตัวอย่าง PMS: PA 80 + CC 20)
  5. รับทราบผล หรือกดไม่เห็นด้วยพร้อมเหตุผล
  6. จัดทำ IDP ไม่เกินประมาณ 2 รายการต่อปี วิธีพัฒนา 70 / 20 / 10
