## เอกสารที่ 1 — `MUIT-APP-MUHR-PA-UM-01-V03.pdf`

**ชื่อเรื่อง:** คู่มือการใช้งาน การประเมินสมรรถนะออนไลน์ (Competency Online) สำหรับผู้ประเมิน  
**รหัส:** MUIT-APP-MUHR-PA-UM-01 รุ่น 3.0 (16 ก.พ. 2561)  
**ผู้จัดทำเอกสาร:** นางอกนิษฐ์ ภูเขาทอง กองเทคโนโลยีสารสนเทศ  
**สารบัญ:** เข้าสู่ระบบ → ประเมินสมรรถนะ → ยืนยันการส่งผล → สอบถามข้อมูล/พิมพ์รายงาน → ช่วยเหลือ → ออกจากระบบ → แก้ปัญหา

### 1.1 โปรแกรมนี้คืออะไร

- เป็น **โมดูลหนึ่ง** ในระบบ e-Performance Appraisal แบบ Web Application
- วัตถุประสงค์: ให้ **ผู้ประเมิน** เข้าไปให้คะแนนสมรรถนะของ **ผู้รับการประเมิน** ผ่านเครือข่ายมหาวิทยาลัย
- งานเตรียมข้อมูลรอบประเมินเป็นหน้าที่ **เจ้าหน้าที่งานทรัพยากรบุคคลของส่วนงาน** ไม่ใช่งานของผู้ประเมินในคู่มือนี้
- คู่มือนี้ **ไม่ใช่หน้ากรอกภาระงาน/ตัวชี้วัด PA** — หน้าที่นั้นอยู่ที่ UM-03 (ผู้รับการประเมิน) และที่ PMS (ระบบใหม่)

### 1.2 หน้าตาโปรแกรม

**หน้า Login**

- Header น้ำเงิน: ตราพระเกี้ยว + คำว่า `Mahidol University` + `e-Performance Appraisal System`
- กล่อง “เข้าสู่ระบบ”: รหัสผู้ใช้งาน / รหัสผ่าน / ปุ่ม `Log in`
- พื้นหลังเป็นภาพห้องปฏิบัติการ + ภาพย่อย 4 รูปมุมล่าง
- Copyright กองเทคโนโลยีสารสนเทศ สำนักงานอธิการบดี ปี 2012

**หลัง Login — เลือกปีงบประมาณ / ช่วงเวลาการประเมิน**

- ต้องระบุปีงบประมาณและรอบก่อนเข้าเมนูหลัก

**หน้าหลัก (ปฏิทิน + แถบเมนู)**

- แถบเมนูน้ำเงินด้านบนของระบบเดียวกัน รายการที่เห็นขึ้นกับสิทธิ์
- คู่มือผู้ประเมินระบุ 4 เมนูที่ใช้ในเล่มนี้:
  1. **ประเมินผล** — ประเมินสมรรถนะ
  2. **สอบถามข้อมูล/พิมพ์รายงาน** — รายงานจุดเด่นและข้อควรพัฒนา
  3. **การช่วยเหลือ** — ดาวน์โหลดคู่มือ PDF
  4. **ออกจากระบบ**
- ภาพตัวอย่างหน้าหลักยังเห็นเมนูอื่นของระบบเดียวกันด้วย เช่น จัดทำข้อตกลงการปฏิบัติงาน, ติดตามข้อมูล, รับทราบผลการประเมิน (เมนูเหล่านี้ไม่ได้อธิบายในเล่มนี้)
- กลางหน้า: ตารางปฏิทินการดำเนินงาน (กิจกรรม / วันที่เริ่มต้น / วันที่สิ้นสุด) ของส่วนงาน
- มุมขวา: ชื่อผู้ใช้งาน + สิทธิ์ปัจจุบัน เช่น ผู้ประเมิน

**หน้ารายชื่อผู้รับการประเมิน (เมนูประเมินผล)**

แบ่ง 3 ส่วน

1. **กล่องคำอธิบายขั้นตอน** (กรอบแดง) 6 ข้อ + คำอธิบายสัญลักษณ์สถานะ
2. **ตารางรายชื่อ** คอลัมน์:
   - เลือกทั้งหมด / ลำดับที่ / ชื่อ-นามสกุล / ตำแหน่ง
   - ประเภทสมรรถนะ 3 ช่องติ๊ก: **Core Competency (CC)** / **Functional Competency (FC)** / **Managerial Competency (MC)**
   - สถานะการยืนยันผลการประเมิน
   - สถานะผู้รับการประเมิน: ติ๊ก “ประเมินไม่ได้” หรือ “ประเมินได้”
3. **ปุ่มทำงาน** เช่น ยกเลิก

สัญลักษณ์สถานะในคู่มือ

- ไอคอนสมุด = อยู่ระหว่างประเมินผลสมรรถนะ
- ช่องว่าง = รอยืนยันผลการประเมินสมรรถนะ
- วงกลมเขียว = ยืนยันผลการประเมินสมรรถนะแล้ว (แก้ไม่ได้)
- ช่องดำทึบ = ไม่ต้องประเมินสมรรถนะประเภทนั้น
- ช่องว่าง = ยังไม่ประเมินสมรรถนะ
- ติ๊กดำ = ประเมินสมรรถนะ (ยังไม่สมบูรณ์)
- ติ๊กเขียว = ประเมินสมรรถนะเรียบร้อยแล้ว

**หน้าให้คะแนนสมรรถนะ (เลือกชื่อคนแล้ว)**

แบ่ง 4 ส่วน

1. ข้อมูลส่วนตัวผู้รับการประเมิน
2. แถบประเภทสมรรถนะ 3 แถบ: **สมรรถนะหลัก (CC)** / **สมรรถนะเฉพาะตามสายอาชีพ (FC)** / **สมรรถนะทางการบริหาร (MC)**
3. ตารางรายการสมรรถนะ + คะแนนที่ได้ + ขยายพฤติกรรมย่อย
4. ความคิดเห็น จุดเด่น / ข้อควรพัฒนา (เพิ่มแถว / ลบแถว)

หน้าให้คะแนนพฤติกรรม (ภาพจริงในคู่มือ)

- แถวสมรรถนะหลัก 7 ข้อ ตรงกับชุดมหาวิทยาลัย:
  1. รู้แจ้ง รู้จริง สมเหตุ สมผล (Mastery)
  2. มุ่งผลเพื่อผู้อื่น (Altruism)
  3. กลมกลืนกับสรรพสิ่ง (Harmony)
  4. มั่นคงยิ่งในคุณธรรม (Integrity)
  5. แน่วแน่ท่า กล้าตัดสินใจ (Determination)
  6. สร้างสรรค์สิ่งใหม่ (Originality)
  7. ใฝ่ใจเป็นผู้นำ (Leadership)
- กด `+` / `-` หน้าชื่อสมรรถนะเพื่อขยาย/หุบพฤติกรรมย่อย หรือปุ่มแสดงทั้งหมด / ยกเลิกแสดงทั้งหมด
- แต่ละพฤติกรรมย่อยให้คะแนน **0–10** เป็นปุ่ม radio สี 4 ช่วง:
  - แดง 0–2 = ไม่เคย/แทบจะไม่เคยแสดง (0–30% ของโอกาส)
  - ส้ม 3–5 = แสดงเป็นบางครั้ง (31–60%)
  - เหลือง 6–8 = แสดงบ่อยครั้ง/เกือบสม่ำเสมอ (61–80%)
  - เขียว 9–10 = แสดงแทบทุกครั้ง/สม่ำเสมอ (81–100%)
- ระบบคำนวณคะแนนสมรรถนะนั้นให้อัตโนมัติ แล้วรวมเป็นคะแนนประเภท

ปุ่มบันทึกมี 2 แบบ (ข้อความต่างกัน)

- บันทึกเมื่อ **ยังประเมินไม่ครบ** (บันทึกค้างได้ กลับมาทำต่อ)
- บันทึกเมื่อ **ประเมินครบถ้วน** ของประเภทนั้น แล้วไปแถบถัดไป
- ปุ่มกลับสู่หน้ารายชื่อ

**หน้ารายงานจุดเด่น/ข้อควรพัฒนา**

- ตาราง: สังกัดที่ประเมิน / ชื่อ-นามสกุล / ตำแหน่ง / ข้อเสนอแนะ (จุดเด่นและข้อควรพัฒนา)
- เลือกจำนวนแถวต่อหน้า: 50 / 100 / 300 / 500 (ค่าเริ่มต้น 50)
- ปุ่ม: ส่งออก Excel / ยกเลิก / ปิดกลับเมนูหลัก
- พิมพ์จาก Excel ด้วย File/Print

**หน้าช่วยเหลือ**

- Dialog ยืนยันดาวน์โหลด → รายชื่อแฟ้มคู่มือ PDF (ตัวอย่างในเล่ม: `MUIT-APP-MUHR-PA-UM-05-V01.pdf`) → ดับเบิ้ลคลิกเปิด PDF

**ออกจากระบบ**

### 1.3 ลำดับการทำงาน (ผู้ประเมิน)

1. เจ้าหน้าที่ HR ส่วนงานเตรียมข้อมูลและเปิดระบบ
2. ผู้ประเมินเปิด IE 9+ / Chrome / Firefox ไปที่ `http://e-performance.mahidol`
3. Login ด้วย Internet Account มหาวิทยาลัยมหิดล รูปแบบ **ชื่อ.นามสกุล**
4. เลือกปีงบประมาณ + ช่วงเวลาการประเมิน
5. เข้าเมนู **ประเมินผล** ดูรายชื่อผู้รับการประเมินทั้งหมดที่ตนต้องประเมิน
6. คนที่ประเมินไม่ได้ → ติ๊กสถานะผู้รับการประเมิน → กรอกเหตุผลใน Dialog → ยืนยัน
7. คนที่ประเมินได้ → คลิกชื่อ → ให้คะแนนทีละประเภทสมรรถนะ ทีละพฤติกรรม ครบทุกข้อ
8. บันทึกได้แม้ยังไม่ครบ หรือบันทึกเมื่อครบประเภท
9. ระบุจุดเด่น / ข้อควรพัฒนาได้ (ไม่บังคับในขั้นตอนให้คะแนน แต่มีช่องนี้)
10. ทำครบทุกคนแล้ว **ยืนยันการส่งผล** เป็นขั้นแยก (เลือกทีละคน หรือเลือกทั้งหมด)
11. หลังยืนยันแล้วมีสัญลักษณ์หน้าชื่อ และ **แก้คะแนนไม่ได้แล้ว**
12. พิมพ์รายงานจุดเด่น/ข้อควรพัฒนาเป็น Excel ได้หลังยืนยันครบทุกคน

### 1.4 เงื่อนไขที่คู่มือบังคับ

- เบราว์เซอร์: Internet Explorer 9.0 ขึ้นไป หรือ Chrome หรือ Firefox
- รหัสผ่านผิด **5 ครั้งติดกัน** → ระงับ **1 ชั่วโมง** แล้วค่อย login ใหม่
- **ยกเลิกการประเมินสมรรถนะของตนเองไม่ได้**
- เลือกประเมินแถบ CC/FC/MC ลำดับใดก่อนก็ได้ แต่ **ต้องครบทุกประเภทที่ระบบกำหนดให้คนนั้น** (ช่องดำทึบ = ไม่ต้องประเมินประเภทนั้น เช่น MC ของคนที่ไม่ได้เป็นผู้บริหาร)
- สูตรคะแนนรายการสมรรถนะ  
  `C = B / (A × 10) × 100`  
  A = จำนวนพฤติกรรมย่อยในรายการนั้น, B = ผลรวมคะแนนพฤติกรรมย่อย  
  ตัวอย่างในคู่มือ: A=4, คะแนน 8+9+8+9 → C = 85
- สูตรคะแนนประเภทสมรรถนะเทียบสัดส่วน  
  `D = A × C / B`  
  A = คะแนนรวมรายการ, B = จำนวนรายการสมรรถนะ × 100, C = สัดส่วนของประเภทนั้น  
  ตัวอย่าง: A=85, B=7×100=700, C=10 → D = 1.21 (สมรรถนะหลัก 10%)
- ยืนยันส่งผลได้ **เมื่อประเมินครบทุกประเภทแล้วเท่านั้น**
- ยืนยันส่งแล้ว **immutable** — แก้ไม่ได้
- ถ้ายังไม่มี Internet Account: สมัครที่ `http://myinternet.mahidol/signup/` หรือเปิดใช้งานที่ `https://myinternet.mahidol.ac.th/staffactivate.php` แล้วแจ้งอีเมลชื่อ.นามสกุล 3 ตัวอักษร `@mahidol.ac.th` ให้ HR ส่วนงานบันทึก MUERP / Non-MUERP (SI, RA, DT, OPGJ) และนำเข้า MUHR CPD
- ไม่มีสิทธิ์: ผู้ดูแลระบบส่วนงานติดต่อ กองทรัพยากรบุคคล 0-2849-6277

- เปลี่ยนรหัส: `https://myinternet.mahidol.ac.th/staffpwdmod.php`

**สารบัญ:** เข้าสู่ระบบ → เตรียมข้อมูลข้อตกลง → ปรับ/แก้ไขเมื่อหัวหน้าส่งกลับ → เพิ่มเติม/แก้ไข/ยกเลิกหลังเห็นชอบ → รายงานผลการปฏิบัติงาน → ออกจากระบบ → แก้ปัญหา

### 2.1 โปรแกรมนี้คืออะไร

- โมดูลหนึ่งใน **e-Performance Appraisal System** ชุดเดียวกับ UM-01 แต่เป็นฝั่ง **ผู้รับการประเมิน**
- ใช้ทำ 3 งานใหญ่:
  1. จัดทำข้อตกลงการปฏิบัติงาน (PA) ตอนต้นรอบ
  2. เพิ่มเติม / แก้ไข / ยกเลิกข้อตกลง หลังผู้บังคับบัญชาเห็นชอบแล้ว
  3. รายงานผลการปฏิบัติงาน ปลายรอบ (ใส่หลักฐานในคอลัมน์ 8)
- Admin ส่วนงานเป็นคนเปิดระบบ และเตรียมข้อมูลพื้นฐาน: ผู้รับการประเมิน, ผู้ประเมิน (ผู้บังคับบัญชาขั้นต้น), ผู้ประเมิน (ผู้บังคับบัญชารองลงมา), กำหนดผู้ประเมิน, กำหนดเกณฑ์, ปฏิทิน

### 2.2 หน้าตาโปรแกรม

**Login / เลือกปีงบประมาณ** — หน้าตาเดียวกับ UM-01 (ระบบเดียวกัน)

**หน้าหลักของผู้รับการประเมิน** — เมนู 4 รายการตามคู่มือนี้

1. **จัดทำข้อตกลงการปฏิบัติงาน** — เตรียมข้อมูล / เพิ่มเติมแก้ไขยกเลิก / รายงานผล (เมนูเดียว หลายจังหวะตามปฏิทิน)
2. **ประเมินผล** — ประเมินผลการปฏิบัติงาน (คู่มือเล่มนี้ **ไม่อธิบายหน้านี้** ไปอยู่เล่มผู้ประเมิน/สมรรถนะ)
3. **การช่วยเหลือ** — ดาวน์โหลดคู่มือ
4. **ออกจากระบบ**

มุมขวาตัวอย่าง: ผู้ใช้งาน อกนิษฐ์ ภูเขาทอง / สิทธิ์ปัจจุบัน : ผู้รับการประเมิน  
กลางหน้า: ปฏิทิน เช่น “จัดทำข้อตกลงการปฏิบัติงาน 01 เม.ย. 2558 – 30 ก.ย. 2558”

**ขั้นที่ 1 หลังเข้าเมนูจัดทำข้อตกลง = หน้าประวัติส่วนตัว (บังคับยืนยันก่อนกรอก PA)**

ตารางสองคอลัมน์ สีเทา/ฟ้า เช่น

- คำนำหน้าชื่อ (สามัญ) / คำนำหน้าชื่อ (ตำแหน่งวิชาการ) / ยศทางทหาร
- ชื่อ-นามสกุล ไทยและอังกฤษ
- ตำแหน่ง / ตำแหน่งความก้าวหน้าตามสายอาชีพ / ตำแหน่งบริหาร
- กลุ่มบุคลากร (เช่น ข้าราชการ) / กลุ่มย่อย (เช่น วิชาชีพเฉพาะ)
- วันที่เริ่มทำงานใน ม.มหิดล / อายุงาน
- อีเมล ม.มหิดล / ส่วนงาน / ภาควิชา / ฝ่าย / งาน / หน่วย

ปุ่ม 3 ปุ่ม: **ยืนยันข้อมูล** / **แก้ไขข้อมูล** / **ยกเลิก** (กลับเมนูหลัก)

**หน้า A — ข้อตกลงการปฏิบัติงานล่วงหน้า (หัวใจของคู่มือนี้)**

หัวข้อ “ส่วนที่ 2 ข้อมูลข้อตกลงการปฏิบัติงานล่วงหน้า (Performance Agreement)”  
คำชี้แจง 4 ข้ออยู่เหนือตาราง รวมประเด็นสำคัญ: กรอกคอลัมน์ 2–6, น้ำหนักตัวชี้วัดในแต่ละข้อรวม 100, **น้ำหนักรวมของภาระงานทั้งฉบับต้องเท่ากับ 100**

ตาราง 9 คอลัมน์

| คอลัมน์ | ชื่อ | ทำอะไร |
| --- | --- | --- |
| (1) | ลำดับที่ | ระบบใส่ให้ |
| (2) | ประเภทของงาน | **dropdown** เช่น งานยุทธศาสตร์ (มหาวิทยาลัย) — ผู้ใช้เลือกเอง |
| (3) | ข้อตกลงการปฏิบัติงาน (ภาระงาน) | กล่องข้อความอิสระ |
| (4) | ค่าน้ำหนักข้อตกลง (ภาระงาน) | ตัวเลข เช่น 50 |
| (5) | ตัวชี้วัดความสำเร็จของงาน | ติ๊กได้หลายด้าน: **ปริมาณ / คุณภาพ / เวลา / ความคุ้มค่า / ความพึงพอใจ** |
| (6) | ค่าน้ำหนักของตัวชี้วัดที่กำหนด (ร้อยละ) | ช่องตัวเลขต่อด้านที่ติ๊ก รวมต้องได้ 100 |
| (7) | ร้อยละ (น้ำหนัก) = คอลัมน์ (4) × คอลัมน์ (6) / 100 | **คำนวณให้อัตโนมัติ อ่านอย่างเดียว** |
| (8) | รายละเอียดข้อตกลงและเกณฑ์การประเมินตามตัวชี้วัด | ตอนจัดทำข้อตกลงใช้ปุ่มลูกศรเขียว “ดำเนินการกำหนดเกณฑ์การประเมิน”; **ตอนรายงานผล** ช่องนี้กลายเป็นที่ใส่เอกสารหลักฐาน |
| (9) | เพิ่ม / แก้ไข / ลบ | สัญลักษณ์ `+` เพิ่มแถว, ดินสอแก้ไข, ถังขยะลบ, ลูกศรกำหนดเกณฑ์, ไอคอนดูรายละเอียด, ยกเลิกการแก้ไข |

แถวสรุปล่างตาราง: **รวมค่าน้ำหนักข้อตกลงการปฏิบัติงาน (ภาระงาน)** และ **รวมร้อยละ (น้ำหนัก)**

ปุ่มล่าง 3 ปุ่ม

- **ยืนยันการส่งข้อตกลงการปฏิบัติงาน** (ไอคอนถูกเขียว)
- **บันทึกและดำเนินการกำหนดเกณฑ์การประเมิน**
- **ยกเลิก** (ป้ายห้ามสีแดง)

ตัวอย่างในคู่มือแถวที่ 1: ประเภท = งานยุทธศาสตร์ (มหาวิทยาลัย), ภาระงาน = “วิเคราะห์และออกแบบระบบ e-Performance Appraisal โมดูล e-PA”, น้ำหนักภาระงาน 50, ติ๊กคุณภาพ 60 + เวลา 40 รวม 100, คอลัมน์ (7) ได้ 30 และ 20 รวม 50

**หน้า B — รายละเอียดตัวชี้วัดและเกณฑ์ 5 Scale**

เปิดจากปุ่มลูกศรเขียวที่คอลัมน์ (8)

คอลัมน์หน้า B

- (1)–(5) ดึงมาจากหน้า A อ่านอย่างเดียว (ลำดับ, ประเภทงาน, ข้อตกลง, น้ำหนักภาระงาน, ตัวชี้วัด+ร้อยละ)
- (6) รายละเอียดของตัวชี้วัดแต่ละด้าน — คลิกคำว่า “โปรดระบุ” เปิดกล่องกรอก แล้วกด “ปิด”
- (7) เกณฑ์การประเมินผลการปฏิบัติงานตามตัวชี้วัด **5 Scale** — คลิก “โปรดระบุ” กรอกทีละระดับ ต้องครบทั้ง 5

ปุ่มหน้า B: **ย้อนกลับไปหน้า A** / **บันทึกข้อมูลเกณฑ์การประเมิน** (มี Dialog ยืนยัน)

หมายเหตุในคู่มือ: ต้องระบุรายละเอียดตัวชี้วัดให้ครบทุกด้านที่ติ๊ก

**หน้าพรีวิวก่อนส่ง**

หลังกดยืนยันการส่ง ระบบโชว์ 3 บล็อกให้ตรวจ

1. ข้อมูลส่วนตัวของบุคลากร
2. ข้อตกลงการปฏิบัติงาน
3. เกณฑ์การประเมินการปฏิบัติงานตามตัวชี้วัด

### 2.3 ลำดับการใช้งาน แยกตามจังหวะในรอบ

**จังหวะ ก. จัดทำข้อตกลงครั้งแรก (บทที่ 2)**

1. Login → เลือกปีงบประมาณ/รอบ → เมนูจัดทำข้อตกลง
2. ตรวจประวัติส่วนตัว → แก้แล้วบันทึก (มี Dialog) หรือยืนยันถ้าถูก
3. กรอกหน้า A คอลัมน์ 2–6 ทีละข้อ
4. กดกำหนดเกณฑ์ → กรอกหน้า B คอลัมน์ 6 และ 7 (5 Scale ครบ)
5. บันทึกเกณฑ์ → กลับหน้า A
6. กด `+` เพิ่มข้อถัดไป ทำซ้ำจนน้ำหนักภาระงานรวม = 100
7. แก้ไขด้วยไอคอนแก้ไข / ยกเลิกการแก้ไข / ลบ (มี Dialog ยืนยันลบ)
8. กดยืนยันส่ง → พรีวิว 3 ส่วน → พิมพ์ Excel ได้ → ยืนยันส่งจริง

**จังหวะ ข. ผู้บังคับบัญชาส่งกลับแก้ไข (บทที่ 3)**

- เข้าเมนูเดิม จะเจอข้อตกลงชุดเดิม
- **มีสัญลักษณ์ดูประวัติข้อเสนอแนะ** (บทที่ 2 ไม่มี)
- อ่านหมายเหตุของหัวหน้า → ปิด → กดแก้ไขแถวตามหมายเหตุ → แก้หน้า A และหน้า B → บันทึก → ยืนยันส่งอีกครั้ง (พรีวิว 3 ส่วนเหมือนเดิม)

**จังหวะ ค. หลังหัวหน้าเห็นชอบแล้ว ยังเพิ่มเติม/แก้ไข/ยกเลิกได้ (บทที่ 4)**

- เข้าเมนูแล้วขึ้น **Dialog ถามก่อน** ว่าจะเพิ่มเติม/แก้ไข/ยกเลิกหรือไม่
- ตกลงถึงเข้าหน้า A; ยกเลิกกลับหน้าหลัก
- แก้ของเดิม / เพิ่มข้อใหม่ (กรอกคอลัมน์ 2–6 แล้วกำหนดเกณฑ์คอลัมน์ 6–7 หน้า B) / ลบได้
- ส่งใหม่ผ่านพรีวิว 3 ส่วนเหมือนจังหวะแรก

**จังหวะ ง. รายงานผลการปฏิบัติงานปลายรอบ (บทที่ 5)**

1. เข้าเมนูเดิม เจอตารางข้อตกลงที่เคยส่งและได้รับความเห็นชอบแล้ว
2. **ไม่สร้างข้อตกลงใหม่** — ไปกรอกเอกสารหลักฐานใน **คอลัมน์ที่ 8** โดยคลิก “โปรดระบุ”
3. บันทึก (Dialog ยืนยัน)
4. กดยืนยันส่งรายงานผล → พรีวิว **2 ส่วน** เท่านั้น (ข้อมูลส่วนตัว + ข้อตกลงการปฏิบัติงาน) ไม่มีบล็อกเกณฑ์ 5 Scale แบบตอนส่งข้อตกลง
5. พิมพ์ Excel ได้ แล้วยืนยันส่ง

**ออกจากระบบ** — Dialog ยืนยัน เหมือน UM-01

### 2.4 เงื่อนไขที่คู่มือบังคับ

- เบราว์เซอร์เดียวกับ UM-01 (IE 9+ / Chrome / Firefox)
- Login: Internet Account **ชื่อ.นามสกุล 3 ตัว**
- รหัสผ่านผิด **3 ครั้ง** → ระงับ Username **10 นาที** แล้ว login ใหม่ (ต่างจาก UM-01 ที่ 5 ครั้ง / 1 ชั่วโมง)
- ต้องยืนยันประวัติส่วนตัวก่อนเข้าหน้ากรอกข้อตกลง
- **ค่าน้ำหนักรวมของภาระงานทั้งฉบับ = 100** มิฉะนั้นยังส่งไม่ได้ตามคำชี้แจงบนหน้าจอ
- ในแต่ละข้อตกลง ค่าน้ำหนักตัวชี้วัดด้านที่ติ๊ก **รวมเป็น 100**
- คอลัมน์ (7) คำนวณอัตโนมัติ ไม่กรอกเอง
- หน้า B ต้องกรอกตัวชี้วัดครบทุกด้าน และเกณฑ์ครบ **5 Scale**
- ส่งข้อตกลงแล้วหัวหน้าตรวจได้ ส่งกลับได้ มีประวัติข้อเสนอแนะ
- หลังเห็นชอบแล้วยังขอเพิ่มเติม/แก้ไข/ยกเลิกได้ (มี Dialog กันกดพลาด)
- รายงานผลใช้คอลัมน์ 8 เป็นหลักฐาน ไม่ใช่หน้าอัปโหลดแยกต่างหากในคู่มือนี้
- ไม่แนะนำให้เบราว์เซอร์จำรหัสผ่าน (มีบทแก้ปัญหา IE Tools/Internet Options)
- ไม่มีรหัส: ติดต่อ HR ส่วนงานเพื่อขอ Internet Account

### 3.1 โปรแกรมนี้คืออะไร (ภาพรวมระดับมหาวิทยาลัย)

ไม่ใช่ฟอร์มวิจัยชิ้นเดียว แต่เป็นระบบครบวงจรของพนักงานมหาวิทยาลัย

กระบวนการทั้งรอบ (สไลด์ infographic, รอบตัวอย่าง 1 ก.ค. – 30 มิ.ย.)

1. **จัดทำ PA** ภายในเดือนมิถุนายน — ผู้ปฏิบัติงาน + ผู้บังคับบัญชาขั้นต้น
2. **รายงานผลการดำเนินงาน และประเมินตนเอง**
3. **ประเมินผล (PA + Competency)** — ผู้บังคับบัญชาขั้นต้นเป็นผู้ประเมิน
4. **คณะกรรมการประเมิน** พิจารณารับรอง จัดกลุ่มคะแนน สรุปผลเสนอภายในเดือนกรกฎาคม — ภายใน 7 วันนับแต่คณะกรรมการประเมินแล้วเสร็จ
5. **หัวหน้าส่วนงาน/หัวหน้าหน่วยงาน ลงนามรับผลประเมิน** ของผู้ปฏิบัติงานทั้งส่วนงาน
6. **แจ้งผลการประเมิน + Feedback** — ภายใน 15 วันนับแต่หัวหน้าส่วนงานลงนามรับผล
7. **ผู้ปฏิบัติงานรับทราบผลการประเมิน**
8. จากนั้น **จัดทำ IDP**

หมายเหตุบนสไลด์: ระหว่างรอบประเมิน ให้ผู้บังคับบัญชาขั้นต้นติดตามความคืบหน้าการดำเนินงานตาม PA

โมดูลที่คำแนะนำนี้สอน (9 ข้อ เรียงตามวงจร ไม่ใช่เมนูเดียว)

1. จัดทำข้อตกลงการปฏิบัติงาน (PA)
2. รายงานผลการปฏิบัติงาน (PA)
3. ประเมินผลงาน และประเมินสมรรถนะ
4. แจ้งผลและรับทราบผลการประเมินการปฏิบัติงาน
5. จัดทำแผนพัฒนารายบุคคล (IDP)
6. รายงานผลการพัฒนารายบุคคล (IDP)
7. ประเมินผลการพัฒนารายบุคคล (IDP) เป็นไปตามที่คาดหวัง / ไม่เป็นไปตามที่คาดหวัง
8. แจ้งผลและรับทราบผลการพัฒนารายบุคคล (IDP)
9. รายงานและติดตามผลการดำเนินการ (REPORT)

ปุ่มขวาบน: **Import Excel ชุดชี้วัด** / **นำเข้าจาก Template** / **นำเข้าจากรอบประเมินก่อนหน้า** / **ซ่อนคำอธิบาย**

ตารางลำดับชั้น 4 ระดับต่อภารกิจ ไม่ใช่แถวผลงานวิจัย

- แถวหัวสีน้ำเงินเข้ม: **ภาระงานที่ 1 / 2 / 3 / 4** + ช่องข้อความคำอธิบายภารกิจ + ปุ่ม `+` `−` สร้าง/ลบภารกิจ
- แถวรอง: **ข้อตกลง x.1**
- แถวรอง: **ตัวชี้วัด x.1.1**
- แถวล่าง: **เป้าหมาย x.1.1.1** + dropdown ประเภทตัวชี้วัด + ร้อยละของเป้าหมาย + ไอคอนตารางเกณฑ์การประเมิน + dropdown สถานะอนุมัติ (ค่าเริ่มต้น “รออนุมัติ”) + ความคิดเห็นของผู้อนุมัติ

ข้อความเริ่มต้นของ 4 ภาระงานบนหน้าจอจริงในสไลด์

- **ภาระงานที่ 1** = งานตามภารกิจที่สอดคล้องกับประเด็นยุทธศาสตร์ของมหาวิทยาลัยและแผนกลยุทธ์ของส่วนงาน
- **ภาระงานที่ 2** = งานตามภารกิจหลักของตำแหน่งงาน งานหน้าที่ความรับผิดชอบ ตามคำบรรยายลักษณะงาน
- **ภาระงานที่ 3** = งานตามภารกิจที่ได้รับมอบหมาย (เพื่อเป็นการพัฒนางาน ศักยภาพ และขีดความสามารถของบุคลากร)
- **ภาระงานที่ 4** = งานตามภารกิจเพื่อส่วนรวม (เพื่อสนับสนุนการมีส่วนร่วม และ/หรือ การร่วมกิจกรรมของคณะฯ)

ข้อย่อยภายใต้ภาระงานที่ 4 ในหน้าจอเป็น **ข้อตกลง 4.1, ตัวชี้วัด 4.1.1, เป้าหมาย 4.1.1.1** ตามชั้นของฟอร์ม ใช้ให้คะแนนหัวข้อนั้น ๆ

มุมบนขวา: จำนวนเป้าหมาย + **รวมร้อยละ (ค่าน้ำหนัก) ของตัวชี้วัด** (ต้องคุมให้ครบตามกฎ)  
ปุ่มล่าง: **บันทึกฉบับร่าง** / **ยกเลิก** / **ขออนุมัติ**  
ท้ายฟอร์มมีตารางลงนามข้อตกลงปฏิบัติ: ลงนามผู้รับการประเมิน / ลงนามผู้บังคับบัญชา + วันที่ส่ง

**ไฟล์ Excel Macro `MDsource…` (กรณีที่ 1)**

ชีต: `PA` / `Criteria` / `import` / `options`  
แถวบนชีต PA: ปุ่ม **ล้างข้อมูล**, ช่องผู้รับการประเมิน / ตำแหน่ง / สังกัด, ปุ่ม **สร้างเอกสารสำหรับ import**, ช่องร้อยละค่านำหนัก (100) สีเหลือง (รวมอัตโนมัติ)

หัวคอลัมน์แถวกรอก (สีฟ้า/ส้ม/ชมพู/เขียว)

1. ประเภทภาระงาน (dropdown ภารกิจที่ 1–4 ตามนิยามด้านบน)
2. ลำดับที่ข้อตกลง (ต้องเรียง 1,2,3,…)
3. ภาระงานที่ทำข้อตกลงการปฏิบัติงาน
4. ประเภทตัวชี้วัด (เวลา / ปริมาณ / คุณภาพ / ความคุ้มค่า / ความพึงพอใจ)
5. หมายเลขของตัวชี้วัด (เรียงในแต่ละข้อตกลง)
6. ตัวชี้วัดเป้าหมายความสำเร็จของภาระงาน
7. ค่าน้ำหนักข้อตกลง (ร้อยละ)
8. ค่าน้ำหนักตัวชี้วัด (ร้อยละ) — **ในแต่ละข้อตกลงรวมได้ 100**

ชีต Criteria: ปุ่มคัดลอกข้อตกลงจากชีต PA มา แล้วกรอกเกณฑ์การประเมิน 5 ช่วง  
ชีต import: กดปุ่มให้ขึ้นข้อความ `import data generated complete.` ถ้าไม่ขึ้น = กรอกไม่ครบหรือไม่ถูก แล้วแปลงรหัสข้อความพร้อมนำเข้า  
จากนั้น copy ทั้งชีต import ไปไฟล์ xlsx ใหม่ ตั้งชื่อเอง เช่น `PA นายAA BB 68_ใช้ Import.xlsx`

### 3.3 ลำดับการใช้งานใน PMS1

**กรณีที่ 1 สร้าง PA จาก Excel แล้ว Import**

1. ดาวน์โหลดฟอร์ม Excel Macro `MDsource…` จากทางเข้า PMS
2. คลิกขวา → Extract All → เปิดไฟล์ในโฟลเดอร์ที่แตกแล้ว
3. ถ้า Excel บล็อกแมโคร: Enable Content / ปรับ Trust Center ตามภาพในสไลด์ (7 คลิก)
4. กรอกตัวตนบนชีต PA ให้ครบ
5. กรอกข้อตกลงตามคอลัมน์ 1–8 น้ำหนักตัวชี้วัดต่อข้อ = 100, น้ำหนักภาระงานรวมอัตโนมัติ
6. ไปชีต Criteria คัดลอกข้อตกลงเข้ามา แล้วกรอกเกณฑ์ 5 ช่วงให้ครบ
7. ไปชีต import กดสร้าง ต้องขึ้น complete
8. Copy ชีต import ทั้งแผ่นไปไฟล์ Excel ใหม่ บันทึกเป็น .xlsx
9. เข้า myPMS → KPI → รอบการประเมิน → เลือกปี/ประเภทบุคลากรของหน่วยงาน
10. คลิก **กำหนดตัวชี้วัด** ของแบบประเมินข้อตกลง PA
11. Import เลือกไฟล์ → จับคู่หัวคอลัมน์ให้ขึ้นครบทุกคอลัมน์ → ตรวจข้อมูลผิดพลาด (ถ้ากดแล้วไม่ขึ้นรายการ = ไม่มี error)
12. ข้อมูล PA + เกณฑ์โผล่ในระบบ
13. กดส่งขออนุมัติให้ประธาน (หัวหน้า) → ยืนยัน → สถานะเป็น **ขออนุมัติ**

**กรณีที่ 2 กรอกในระบบโดยตรง**

กรอกทีละชั้นในหน้า PA

- ภาระงาน = ประเภท 1–4 ตามนิยามข้างต้น
- ข้อตกลง และตัวชี้วัด **กรอกข้อความให้เหมือนกัน** เช่น ข้อตกลง 2.1 = ตัวชี้วัด 2.1 = “การพัฒนา Global Talent สายสนับสนุน”
- ค่าน้ำหนักของตัวชี้วัด = ร้อยละของข้อตกลงนั้น
- เป้าหมาย = ตัวชี้วัดความสำเร็จย่อย เช่น “เป้าหมาย 2.1.1.1 (ร้อยละ 100) ร้อยละความสำเร็จของการดำเนินการตามแผน…”
- ประเภทตัวชี้วัด 5 แบบ: เวลา ปริมาณ คุณภาพ ความคุ้มค่า ความพึงพอใจ
- ร้อยละของเป้าหมายในแต่ละข้อตกลงรวม = 100
- เกณฑ์การประเมิน = รายละเอียดแต่ละช่วงคะแนน (มีตัวอย่างตารางในสไลด์)
- บันทึก → ขออนุมัติ → ยืนยัน → สถานะ “ขออนุมัติ”

**ประธานอนุมัติข้อตกลง PA**

1. ถ้ามีหลายคน ค้นจากชื่อสกุล และ/หรือแบบประเมิน
2. เข้า **กำหนดตัวชี้วัด** ของชุดนั้นทีละคน
3. ตรวจรวมร้อยละค่าน้ำหนัก
4. ทางเลือก
   - อนุมัติทีละข้อ: เปลี่ยนสถานะจาก รออนุมัติ เป็น **อนุมัติ** ทุกข้อ แล้วบันทึก
   - อนุมัติทั้งหมดทุกข้อตกลง: กดปุ่มอนุมัติทั้งหมด แล้วยืนยัน
   - ส่งกลับแก้: เปลี่ยนเป็น **ไม่อนุมัติ** ใส่เหตุผลด้านหลังช่องไม่อนุมัติ แล้วบันทึก

**รายงานผลการดำเนินงาน และประเมินตนเอง (แบบ PA) — ท้าย PMS1**

1. จากชุดประเมิน คลิก **ประเมินผล** ของแบบข้อตกลง PA
2. คลิกไอคอนรายงานผลในแต่ละเป้าหมาย
3. กล่อง “ผลการดำเนินงาน”: ตารางเกณฑ์ 5 แถว (คะแนนต่ำสุด–สูงสุด + ความหมาย + ติ๊กคาดหวัง) ช่องพิมพ์คำอธิบาย เลือกไฟล์แนบหลักฐาน ปุ่ม `+ เพิ่มรายงานผลการดำเนินงาน`
4. หัวข้อประเมินตนเอง ใส่คะแนน
5. บันทึก / ส่งผลการประเมิน
6. **ข้อควรระวังตัวโตในสไลด์:** ตรวจคะแนนให้แน่ใจก่อนคลิกส่ง เพราะส่งแล้วแก้ไม่ได้

ตัวอย่างเกณฑ์ในกล่องรายงานผล (ภาพจริง)

- ได้สูงกว่าเป้าหมาย 9–10 = ดำเนินการตามแผนมากกว่า ร้อยละ 80
- ได้ตามเป้าหมาย 7–8 = ตามแผน ร้อยละ 80 (แถวที่ติ๊กคาดหวังในตัวอย่าง)
- ได้ใกล้เคียง 5–6 = ร้อยละ 70
- ได้ต่ำกว่า 3–4 = ร้อยละ 60
- ได้ต่ำกว่ามาก 0–2 = น้อยกว่า ร้อยละ 60

## เอกสารที่ 4 — `แนะนำระบบ PMS2.pdf` (สไลด์ต่อจาก PMS1)

ชุดเดียวกัน เริ่มที่แบบประเมินสมรรถนะ ไปจนถึง IDP, รายงาน, Q&A

สไลด์ไฮไลต์โมดูลที่กำลังสอน: **ประเมินผลงาน และประเมินสมรรถนะ**

### 4.1 หน้าตาที่เหลือของ PMS

**แบบประเมินสมรรถนะหลัก CC (ผู้รับการประเมินประเมินตนเอง)**

ตารางหัวข้อ `กำหนดตัวชี้วัด` แถบ “สมรรถนะหลัก” มุมขวา **รวมน้ำหนัก (ร้อยละ) 700** (ในภาพตัวอย่าง)

7 รายการคงที่ (ชุดเดียวกับ UM-01)

1. Mastery มีสติ เป็นเลิศในงานที่รับผิดชอบ …
2. Altruism ทำเพื่อผู้อื่น …
3. Harmony ประสานความต่าง …
4. Integrity ซื่อสัตย์ สุจริต …
5. Determination มุ่งมั่น ฝ่าฟัน …
6. Originality คิดและทำสิ่งใหม่ …
7. Leadership กล้าคิด กล้าทำ …

คอลัมน์: สมรรถนะหลัก / ผลการดำเนินงาน (ไอคอนรายงานผล) / เกณฑ์การประเมิน (ไอคอนตาราง) / ประเมินตนเอง (ช่องคะแนน+ดินสอ) / ผลการประเมินกรรมการ / ผลการประเมินประธาน / ผลการประเมิน

ปุ่มล่าง: **บันทึก** / **ยกเลิก** / **ส่งผลการประเมิน**

**แบบ FC / MC**

- FC: รายการสมรรถนะเฉพาะตามสายอาชีพ **ตามตำแหน่งและระดับพฤติกรรมตามอายุงาน** (ไม่ใช่ชุดเดียวกันทุกคน)
- MC: เฉพาะผู้ดำรงตำแหน่งบริหาร
- วิธีใช้เหมือน CC: รายงานพฤติกรรม + แนบไฟล์ + ให้คะแนนตนเอง + ส่งแล้วแก้ไม่ได้

**หน้าให้ความเห็นของกรรมการ (ยังไม่ใช่คนให้คะแนนหลัก)**

- เข้าประเมินผลของแบบ PA / CC / FC / MC
- คลิกแต่ละเป้าหมายหรือแต่ละรายการสมรรถนะ
- กล่องความคิดเห็น **ใส่ข้อความได้ และใส่ตัวเลขเป็นคะแนนกำกับได้ (ไม่บังคับว่าเป็นคะแนนหลัก)**
- ต้องให้ความเห็นครบทุกเป้าหมาย/ทุกรายการ แล้วบันทึก และส่งให้ประธาน

**หน้าประเมินของประธานกรรมการ (คนให้คะแนน)**

- กล่องให้คะแนนในช่องคะแนน + ความเห็นในช่องความเห็น
- ประเมินครบทุกเป้าหมายของข้อตกลง / ทุกรายการสมรรถนะ
- บันทึกค้างได้
- ปุ่ม **ตรวจสอบคะแนน** โผล่ **เมื่อกรอกครบทุกข้อทั้งแบบ PA และแบบ CC** (จะกดจากหน้า PA หรือหน้า CC ก็ได้)
- Dialog สรุปคะแนนในภาพ:
  - ผลการประเมินผลการปฏิบัติงาน (Performance) น้ำหนัก 80 คะแนนที่ได้ 80
  - ผลการประเมินสมรรถนะหลัก (Core Competency) น้ำหนัก 20 คะแนนที่ได้ 20
  - รวม 100
  - เกณฑ์ระดับ: ดีเด่น 90.00–100.00 / ดีมาก 80.00–89.99 / ดี 70.00–79.99 / พอใช้ 60.00–69.99 / ควรปรับปรุง ต่ำกว่า 60.00
  - ช่องจุดเด่น / ข้อควรพัฒนา / ข้อเสนอแนะของผู้บังคับบัญชาขั้นต้น
- กด **ส่งคะแนน** แล้วแก้ไม่ได้

**แถบสถานะด้านบนของแบบประเมิน (ภาพกรณีไม่เห็นด้วย)**

ลำดับวงกลม:

1. พนักงานประเมินตนเอง (มีวันที่เวลา)
2. กรรมการประเมิน
3. ประธานกรรมการประเมิน
4. คณะติดลงนาม
5. พนักงานรับทราบประเมินผล
6. เสร็จสิ้น

กรณีไม่เห็นด้วยมีแถบแดง: `เหตุผลพนักงานไม่ยินยอม : …`

**หน้าแจ้งผล / รับทราบ**

- เข้าประเมินผลของแบบนั้น จะเห็นคะแนนรายข้อ
- ปุ่มตรวจสอบสรุป
- ปุ่มรับทราบ
- **คลิกรับทราบในแบบ PA หรือแบบ CC = รับทราบทั้ง PA และ CC พร้อมกัน**
- FC รับทราบแยก
- MC รับทราบแยก (ผู้บริหาร) สรุปคะแนนรวม Managerial Competency; หมายเหตุในสไลด์: สถานะแบบ FC เปลี่ยนเป็น “เสร็จสิ้น” เมื่อจบขั้นตอนนี้ตามบริบทที่สอน

**หน้า IDP**

หัวข้อ `Individual Development Plan (IDP)` ปุ่มชุดเดียวกับ PA (Import/Export Excel, Template, รอบก่อนหน้า, ซ่อนคำอธิบาย)

คำชี้แจงบนจอ (ย่อ)

1. ให้ผู้รับการพัฒนาระบุสมรรถนะ/ทักษะที่พัฒนา 1–2 รายการ, พฤติกรรม/ผลลัพธ์ที่คาดหวัง, วิธีการพัฒนา, ระยะเวลา, งบประมาณ แล้วตกลงร่วมกับผู้บังคับบัญชาขั้นต้น (หัวหน้าอาจเพิ่มรายการจากความเห็นคณะกรรมการได้)
2. ผู้บังคับบัญชาระบุอันดับตามพฤติกรรมหรือผลลัพธ์ที่ได้จริงจากการพัฒนา…

ตารางกรอก: สมรรถนะ/ทักษะที่ต้องได้รับการพัฒนา / พฤติกรรมผลลัพธ์ที่คาดหวัง / วิธีการพัฒนา (dropdown) / รายละเอียด / ระยะเวลาเริ่มต้น-สิ้นสุด / งบประมาณ / ผ่าน / ผู้อนุมัติความคิดเห็น / จัดการ (ลบ)

ปุ่ม: กำหนดตัวชี้วัดสมรรถนะ, บันทึกฉบับร่าง, ยกเลิก, ขออนุมัติ + ตารางลงนาม

**หน้าผล IDP ของผู้รับการประเมิน**

คอลัมน์เพิ่ม: ผลการดำเนินงาน / ผู้ประเมินแสดงความเห็น  
ปุ่ม **ปิด / ตรวจสอบคะแนน / ไม่เห็นด้วย**

ผลที่ประธานให้เป็นข้อความ **เป็นไปตามที่คาดหวัง** หรือ **ไม่เป็นไปตามที่คาดหวัง** (ไม่ใช่คะแนน 0–10 แบบ PA)

**หน้ารายงาน (Admin/ผู้มีสิทธิ์)**

เมนูซ้าย: บุคลากร, ตำแหน่งวิชาการ, โครงสร้างองค์กร, สิทธิ์การใช้งาน, KPI, **รายงาน**, การตั้งค่า  
รายการรายงานอย่างน้อย 19 รายการ เช่น

- รายงานติดตามสถานะข้อตกลง PA / แผน IDP
- รายงานสถานะผลการประเมินภาพรวม / ตาม Metric Code
- รายงานผลการประเมินข้อตกลง PA / สมรรถนะหลัก CC
- รายงานผลการทำงานของกรรมการเต็ม/สั้น
- Auto Change Status
- สรุปผลการประเมิน 2–5 ปี
- สัดส่วนระดับคะแนนผลการประเมิน
- สรุปสัดส่วนรายบุคคลองค์ 9 ของ Competency
- ผลการประเมินข้อตกลง PA / KPI แยกภาระงาน
- ติดตามการประเมินผล / แบบรายบุคคล
- ติดตามแผน IDP / ผล IDP
- แผนผสม log รายละเอียดการประเมิน

### 4.2 ลำดับการใช้งานใน PMS2

**ผู้รับการประเมิน — ประเมินตนเอง CC / FC / MC**

1. ชุดประเมิน → ประเมินผล ของแบบนั้น
2. คลิกแต่ละรายการ (ถ้ามีหลายข้อ)
3. พิมพ์คำอธิบายพฤติกรรม + แนบไฟล์ได้
4. ใส่คะแนนประเมินตนเอง
5. บันทึก แล้วส่ง — ส่งแล้วแก้ไม่ได้

**กรรมการ — ให้ความเห็น PA และสมรรถนะ**

1. ประเมินผล → คลิกแต่ละเป้าหมาย/รายการ
2. เขียนความเห็น ± คะแนนกำกับ
3. ครบทุกข้อ → บันทึก → ส่งให้ประธาน

**ประธาน — ให้คะแนน PA และสมรรถนะ**

1. ประเมินผล → ให้คะแนน+ความเห็นทีละข้อ บันทึกค้างได้
2. เมื่อ PA และ CC ครบทั้งคู่ ปุ่มตรวจสอบคะแนนจึงโผล่
3. ตรวจสรุป 80+20, ระดับคะแนน, จุดเด่น/พัฒนา/ข้อเสนอ
4. ส่งคะแนน — แก้ไม่ได้

**ประธาน — ดูภาพรวม**

- คลิกเข้าหน้ารายงานผลการประเมิน → เลือกหน่วยงาน → ระบบแสดงรายละเอียดผลการประเมินรายคน

**ผู้รับการประเมิน — รับทราบผล**

1. เปิดแบบ PA ดูรายข้อ → ตรวจสอบสรุป PA+CC → รับทราบ (ถือว่า CC ด้วย)
2. เปิดแบบ CC ก็ทำแบบเดียวกัน (รับทราบคู่กัน)
3. เปิดแบบ FC รับทราบแยก
4. ถ้าเป็นผู้บริหาร เปิดแบบ MC ดูคะแนนรายข้อและรวม แล้วรับทราบ

**กรณีไม่เห็นด้วยกับผลการประเมิน**

- ไม่เห็นด้วยคะแนนผลงานและ/หรือสมรรถนะหลักในแบบ PA หรือ CC → กดไม่เห็นด้วย (สถานะ **ทั้ง PA และ CC** กลับเป็นประธานกรรมการประเมิน)
- ไม่เห็นด้วยคะแนน FC → กดไม่เห็นด้วยในแบบ FC
- ไม่เห็นด้วยคะแนน MC → กดไม่เห็นด้วยในแบบ MC
- ต้องระบุเหตุผลละเอียดชัดเจน แล้วบันทึก

**จัดทำ IDP**

1. ชุดประเมิน → กำหนดตัวชี้วัด ของแบบแผนพัฒนาตนเอง IDP
2. กรอก 7 ช่อง: สมรรถนะหรือทักษะ, พฤติกรรม/ผลลัพธ์ที่คาดหวัง, วิธีการพัฒนา 70/20/10, รายละเอียด (หัวข้ออบรม ผู้เกี่ยวข้อง), วันเริ่ม, วันสิ้น, งบประมาณ (ไม่มีก็ใส่ 0)
3. เพิ่มแถวได้ถ้ามีมากกว่า 1 รายการ หรือรายการเดียวแต่หลายวิธี
4. บันทึก → ขออนุมัติ → สถานะเปลี่ยนเป็นขออนุมัติ
5. ตัวอย่างในสไลด์มี 3 แบบ: 1 รายการ 1 วิธี / 1 รายการหลายวิธี / มากกว่า 1 รายการ

**ประธานอนุมัติ IDP** — เหมือนอนุมัติ PA: ทีละข้อ หรืออนุมัติทั้งหมด แล้วยืนยัน

**รายงานผล IDP และประเมินตนเอง**

- ประเมินผลของแบบ IDP → คลิกรายงานผล → พิมพ์รายงานการพัฒนา + แนบไฟล์ → บันทึก/ส่ง — ส่งแล้วแก้ไม่ได้

**ประธานประเมิน IDP** — ให้ผลเป็นไปตามที่คาดหวัง / ไม่เป็นไปตามที่คาดหวัง แล้วส่งผล

**รับทราบผล IDP**

- เห็นผลรายข้อว่าเป็นไปตามที่คาดหวังหรือไม่
- กดรับทราบ
- ถ้าไม่เห็นด้วย: กดไม่เห็นด้วย + เหตุผล → สถานะกลับเป็นประธานกรรมการประเมิน

จบชุดด้วยสไลด์รายงานผลและติดตามผลการดำเนินการ (Report) และ Thank you / Q&A / ขอความร่วมมือประเมินการศึกษาดูงาน

### 4.3 เงื่อนไขที่คำแนะนำนี้บังคับ (ส่วน PMS2)

- CC มี **7 รายการคงที่** ของมหาวิทยาลัย ไม่ใช่ชุดที่คณะคิดเองในหน้านี้
- FC ขึ้นกับตำแหน่งและอายุงาน; MC เฉพาะผู้บริหาร
- กรรมการให้ความเห็น (คะแนนกำกับได้) แต่คนกด **ตรวจสอบคะแนน / ส่งคะแนน** คือประธาน และต้องครบทั้ง PA และ CC
- สัดส่วนสรุปใน Dialog ของภาพตัวอย่าง: **PA 80 + CC 20 = 100** แล้วแปลงเป็น 5 ระดับ
- ส่งคะแนนแล้วแก้ไม่ได้
- รับทราบ PA = รับทราบ CC ด้วย
- ไม่เห็นด้วย PA หรือ CC ส่งผลต่อสถานะทั้งสองแบบ
- IDP **ไม่ควรกำหนดสมรรถนะ/ทักษะเกิน 2 รายการต่อปี**
- วิธีการพัฒนาเลือกจาก dropdown รูปแบบ 70 / 20 / 10
- ผล IDP เป็น “ตามที่คาดหวัง / ไม่ตามที่คาดหวัง”
- ส่งรายงาน IDP แล้วแก้ไม่ได้เช่นกัน

## สิ่งที่โปรแกรมต้องมี ตามเอกสารชุดนี้

- เข้าสู่ระบบ เลือกปีงบประมาณ/รอบ
- จัดทำข้อตกลง: ประเภทภาระงาน → ข้อตกลง → ตัวชี้วัด → เป้าหมาย → เกณฑ์ 5 ช่วง น้ำหนักรวม 100
- หัวหน้าอนุมัติหรือส่งกลับแก้
- รายงานผล แนบหลักฐาน ประเมินตนเอง (ส่งแล้วแก้ไม่ได้)
- ประเมินสมรรถนะ CC 7 ข้อ และ FC/MC ตามตำแหน่ง
- ประธานให้คะแนน (ตัวอย่าง PMS: PA 80 + CC 20) แล้วแจ้งผล รับทราบ หรือไม่เห็นด้วย
- จัดทำและรายงาน IDP
- หัวข้อย่อยในภาระงานเป็นเพียงรายการให้คะแนนในแบบ PA ไม่ใช่ทั้งโปรแกรม

**ยังไม่ลงมือทำโปรแกรมต่อในรอบนี้** ตามที่สั่งให้สรุปเอกสารก่อน
