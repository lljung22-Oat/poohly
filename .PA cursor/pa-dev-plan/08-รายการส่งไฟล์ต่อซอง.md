# รายการส่งไฟล์ต่อซอง — ใช้ตอนกระจายงานให้ AI

อ่านคู่กับ [`05-แบ่งงาน-AI.md`](05-แบ่งงาน-AI.md) และ [`06-เครื่องมือ-AI.md`](06-เครื่องมือ-AI.md)  
เอกสารนี้บอกว่า **ซองไหนส่งให้ใคร** และ **ต้องแนบไฟล์อะไรบ้าง** เพื่อไม่พลาดชุดต้นฉบับ

ยังไม่ลงมือเขียนแกนโปรแกรมในรอบนี้  
หนึ่งแชท = หนึ่งซอง ห้ามรวมหลายซองในครั้งเดียว

## 1. เปิดแชททุกครั้ง ทำตามนี้

1. เลือก AI ตามตารางซองด้านล่าง
2. วางชุดแกน (ข้อ 2) ก่อนเสมอ
3. วางประโยคต้นทางจาก `05-แบ่งงาน-AI.md`
4. เขียนบรรทัดแรกว่า `ทำเฉพาะซอง Sxx` หรือ `อย่าเขียน ซองนี้เป็นของ Cursor`
5. แนบเฉพาะไฟล์ต้นฉบับของซองนั้น จากข้อ 4
6. ถ้าไฟล์ต้นฉบับของซองนั้นยังไม่มีในเครื่อง **อย่าเปิดซองนั้น**
7. เมื่อได้คำตอบ ต้องมีหัวข้อคืนซองครบ แล้วส่งเข้า Cursor ให้หัวหน้าชุดตรวจ ห้ามวางลงคลังรหัสเอง

ประโยคต้นทาง (วางทุกแชท)

```
อ่าน 00-กฏเหล็ก.md และ pa-config.example.json
ทำเฉพาะซองที่ระบุ ตามสัญญาคืนซองใน 05-แบ่งงาน-AI.md
สร้างจริงด้วย React HTML/CSS Tailwind เรียก Node.js Express ค่า chosen เป็น Express ฐาน MySQL
FastAPI และ .NET ห้ามสร้าง
ห้ามเพิ่มตัวแปรใหม่ ใช้ได้เฉพาะคีย์ที่มีใน pa-config.example.json
ถ้าเป็น SOURCE_MISSING ให้หยุด
ห้ามแตะสูตรหน่วย ตารางหลักเกณฑ์ เครื่องสถานะ ประตูสิทธิ์ JWT และโครงสร้างฐานหลัก
สายวิชาการกับสายสนับสนุนแยกหน้า
ป้ายผู้ประเมินคือหัวหน้างานขั้นต้นและหัวหน้างาน
ส่งคืนพร้อมรายการไฟล์และรายการตัวแปร เพื่อให้หัวหน้าชุดตรวจเข้ากันได้
```

## 6. ลำดับส่งงานจริง เพื่อไม่พลาดไฟล์

ทำทีละขั้น ขั้นถัดไปใช้ของขั้นก่อน

1. **เก็บชุดแกนในโปรเจกต์** ChatGPT และ Gemini: ก1–ก4 ทุกครั้ง
2. **อัปโหลดต้นฉบับที่ยังขาด** ลงโฟลเดอร์เดียว ตั้งชื่อตามบัญชีใน `01` ห้ามเปลี่ยนชื่อไฟล์
3. **Gemini EDU คัดช่อง** จาก Word/PDF ลงตาราง ช่องที่ไม่มีในไฟล์เขียน `SOURCE_MISSING`
4. **ส่งตารางคัดนั้นเข้า Cursor** หัวหน้าชุดใส่เข้า config ห้ามให้ Gemini แก้ config เอง
5. **ChatGPT Plus / Terra** ทำ S1 S2 S4 S7 S13 S14 ทีละซอง
6. **Luna** ตรวจคำ S7 และไล่คีย์ว่าซองคืนมาไม่เพิ่มฟิลด์
7. **อย่าเปิด S8–S11 S15** จนกว่าแบบพิมพ์นั้นอยู่ในเครื่องและ config ไม่ใช่ `SOURCE_MISSING`
8. **อย่าเปิด S17 S18** จนกว่า Cursor เขียนโครง C4 C10 C11 แล้ว
9. **S20** ส่งได้เลย เพราะบัญชีส่วนงานคัดแล้ว แต่สั่งให้แสดง lookup อย่างเดียว
10. ทุกคำตอบต้องมีหัวข้อคืนซอง แล้ว Cursor ตรวจรายการเข้ากันได้ใน `05`

## 7. หัวข้อคืนซอง — ผู้รับต้องตอบแบบนี้

```
ซอง: Sxx
ไฟล์ที่แตะ:
- เส้นทางไฟล์
ตัวแปรที่ใช้:
- คีย์ที่มีใน pa-config.example.json เท่านั้น
SOURCE_MISSING:
- ไม่มี หรือระบุคีย์
ตรวจเข้ากันได้: ผ่าน / ไม่ผ่าน พร้อมข้อที่ตก
```

ถ้าคำตอบไม่มีรายการไฟล์หรือมีคีย์ใหม่ ให้ทิ้ง แล้วส่งซองนั้นใหม่
