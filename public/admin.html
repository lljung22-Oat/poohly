import express from 'express'; import fs from 'node:fs/promises'; import path from 'node:path'; import { fileURLToPath } from 'node:url'; const __filename = fileURLToPath(import.meta.url); const __dirname = path.dirname(__filename); const DATA_DIR = path.join(__dirname, 'data'); const DATA_PATH = path.join(DATA_DIR, 'pa-db.json'); const app = express(); const PORT = process.env.PORT || 3000; app.use(express.json({ limit: '1mb' })); app.use(express.static(path.join(__dirname, 'public'))); async function ensureDataFile() { await fs.mkdir(DATA_DIR, { recursive: true }); try { await fs.access(DATA_PATH); } catch { const seed = { appName: 'PA Admin Backend', settings: { language: 'th', theme: 'default', demoTitle: 'PA Demo Preview' }, sections: [ { id: 1, title: 'แผน PA ล่วงหน้า', slug: 'planning', description: 'หัวข้อหลักสำหรับการกำหนดแผน PA ล่วงหน้า', sortOrder: 1, options: [ { id: 101, label: 'การสอน', value: 'teaching', description: 'ภาระงานด้านการสอน' }, { id: 102, label: 'งานวิจัย', value: 'research', description: 'ภาระงานด้านวิจัย' }, { id: 103, label: 'บริการวิชาการ', value: 'service', description: 'ภาระงานด้านบริการ' }, { id: 104, label: 'ภาระงานร่วม', value: 'shared', description: 'ภาระงานร่วมกับทีม' } ] }, { id: 2, title: 'หัวข้อผลงานหลัก', slug: 'main-work', description: 'รายการหลักที่ต้องประเมินและวิเคราะห์ตาม PA', sortOrder: 2, options: [ { id: 201, label: 'ผลงานวิจัย', value: 'research-output', description: 'ผลงานที่นำเสนอและเผยแพร่' }, { id: 202, label: 'การสอนแบบบูรณาการ', value: 'integrated-teaching', description: 'รูปแบบการสอนที่บูรณาการ' }, { id: 203, label: 'ผลงานบริการ', value: 'community-service', description: 'งานบริการที่สร้างคุณค่า' }, { id: 204, label: 'แผนพัฒนาระบบ', value: 'system-improvement', description: 'การปรับปรุงระบบและกระบวนการ' } ] } ] }; await fs.writeFile(DATA_PATH, JSON.stringify(seed, null, 2)); } } async function loadDb() { await ensureDataFile(); const raw = await fs.readFile(DATA_PATH, 'utf8'); return JSON.parse(raw); } async function saveDb(db) { await fs.writeFile(DATA_PATH, JSON.stringify(db, null, 2)); } function sortSections(sections = []) { return [...sections].sort((a, b) => (Number(a.sortOrder) || 0) - (Number(b.sortOrder) || 0)); } function normalizeSection(section) { const clean = section || {}; clean.title = clean.title || 'Untitled section'; clean.slug = clean.slug || clean.title.toLowerCase().replace(/[^a-z0-9]+/g, '-'); clean.description = clean.description || ''; clean.options = Array.isArray(clean.options) ? clean.options.map((option) => ({ id: Number(option.id) || Date.now() + Math.random(), label: option.label || 'New option', value: option.value || option.label || 'new-option', description: option.description || '' })) : []; return clean; } app.get('/api/config', async (_req, res) => { try { const db = await loadDb(); res.json({ appName: db.appName || 'PA Admin Backend', settings: db.settings || {}, sections: sortSections(db.sections || []) }); } catch (error) { res.status(500).json({ message: 'Unable to load config', error: error.message }); } }); app.get('/api/demo', async (_req, res) => { try { const db = await loadDb(); res.json({ appName: db.appName || 'PA Admin Backend', settings: db.settings || {}, sections: sortSections(db.sections || []).map((section) => ({ ...section, options: (section.options || []).map((option) => ({ id: option.id, label: option.label, value: option.value, description: option.description })) })) }); } catch (error) { res.status(500).json({ message: 'Unable to load demo config', error: error.message }); } }); app.get('/api/sections', async (_req, res) => { try { const db = await loadDb(); res.json({ sections: sortSections(db.sections || []) }); } catch (error) { res.status(500).json({ message: 'Unable to load sections', error: error.message }); } }); app.post('/api/sections', async (req, res) => { try { const db = await loadDb(); const payload = normalizeSection(req.body); const sections = db.sections || []; const nextId = sections.reduce((max, item) => Math.max(max, Number(item.id) || 0), 0) + 1; const record = { ...payload, id: Number(payload.id) || nextId, sortOrder: Number(payload.sortOrder) || sections.length + 1, options: Array.isArray(payload.options) ? payload.options : [] }; sections.push(record); db.sections = sortSections(sections); await saveDb(db); res.status(201).json({ section: record }); } catch (error) { res.status(400).json({ message: 'Unable to create section', error: error.message }); } }); app.put('/api/sections/:id', async (req, res) => { try { const db = await loadDb(); const sections = db.sections || []; const index = sections.findIndex((item) => String(item.id) === String(req.params.id)); if (index < 0) { return res.status(404).json({ message: 'Section not found' }); } const updated = normalizeSection({ ...sections[index], ...req.body, id: sections[index].id }); sections[index] = { ...updated, id: sections[index].id, sortOrder: Number(req.body.sortOrder) || sections[index].sortOrder || index + 1, options: Array.isArray(updated.options) ? updated.options : sections[index].options || [] }; db.sections = sortSections(sections); await saveDb(db); res.json({ section: sections[index] }); } catch (error) { res.status(400).json({ message: 'Unable to update section', error: error.message }); } }); app.delete('/api/sections/:id', async (req, res) => { try { const db = await loadDb(); const sections = db.sections || []; const nextSections = sections.filter((item) => String(item.id) !== String(req.params.id)); db.sections = nextSections; await saveDb(db); res.json({ ok: true, removedId: Number(req.params.id) }); } catch (error) { res.status(400).json({ message: 'Unable to delete section', error: error.message }); } }); app.get('/', (_req, res) => { res.sendFile(path.join(__dirname, 'public', 'admin.html')); }); app.get('/demo', (_req, res) => { res.sendFile(path.join(__dirname, 'public', 'demo.html')); }); app.listen(PORT, () => { console.log(`PA admin backend listening at http://localhost:${PORT}`); });
