# เดโม PMS — คณะสังคมศาสตร์และมนุษยศาสตร์

เข้าสู่ระบบด้วย **เลือกโหมด** ไม่ปนหน้าที่ในหน้าเดียว

ปีงบประมาณเริ่มต้น **2570** เลือก **2569** ได้ทุกหน้า

## เปิดใช้

เปิด `index.html` ในเบราว์เซอร์ หรือ

```bash
python3 -m http.server 8765
```

แล้วไปที่ `http://localhost:8765/`

## สิ่งที่อำนวยความสะดวก (ไม่เปลี่ยนหน้าตาต้นฉบับ)

ประกาศหลักเกณฑ์คณะฯ พ.ศ. 2568 เป็นตารางคำนวณด้านหลังของอาจารย์เท่านั้น

- Performance 80% ฐาน 1,820 หน่วย: ยุทธศาสตร์ 25% + ภาระงานหลัก 55% + มอบหมาย 15% + เพื่อส่วนรวม 5%
- Competency 20% จาก CC 7 ข้อ (รวม÷70)×20
- Dialog ประธาน: PA 80 + CC 20 = 100
- น้ำหนักข้อตกลงรวมต้องได้ 100 จึงขออนุมัติได้
- ส่งรายงานผลแล้วแก้ไม่ได้
- IDP ไม่เกิน 2 รายการ วิธีพัฒนา 70 / 20 / 10
