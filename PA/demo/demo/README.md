# เดโม PMS — คณะสังคมศาสตร์และมนุษยศาสตร์

โคลนวงจร **ระบบบริหารผลการปฏิบัติงาน (PMS)** จากคำแนะนำ PMS1+PMS2 (ชุดเดียวกัน) ที่ `https://mypms.mahidol.ac.th/` ไม่ได้ออกแบบเมนูบทบาทใหม่

ผู้ใช้ตัวอย่าง: **น.ส.พรทิพา เซี่ยงฉิน** ตำแหน่งอาจารย์

## เปิดใช้

เปิด `index.html` ในเบราว์เซอร์ หรือ

```bash
python3 -m http.server 8765
```

แล้วไปที่ `http://localhost:8765/`

เข้าสู่ระบบด้วย Internet Account `porntipa.c` (รหัสผ่านอะไรก็ได้ในเดโม)

## 9 โมดูลตามสไลด์ PMS

1. จัดทำข้อตกลงการปฏิบัติงาน (PA)
2. รายงานผลการปฏิบัติงาน (PA)
3. ประเมินผลงาน และประเมินสมรรถนะ
4. แจ้งผลและรับทราบผลการประเมินการปฏิบัติงาน
5. จัดทำแผนพัฒนารายบุคคล (IDP)
6. รายงานผลการพัฒนารายบุคคล (IDP)
7. ประเมินผลการพัฒนารายบุคคล (IDP) เป็นไปตามที่คาดหวัง / ไม่เป็นไปตามที่คาดหวัง
8. แจ้งผลและรับทราบผลการพัฒนารายบุคคล (IDP)
9. รายงานและติดตามผลการดำเนินการ (REPORT)

ชุดประเมินของคนหนึ่งมีแบบ PA, CC, IDP, FC (อาจารย์มี CFC01 / SFC01 / SFC02) ไม่มี MC เพราะไม่มีตำแหน่งบริหาร

## สิ่งที่อำนวยความสะดวก (ไม่เปลี่ยนหน้าตา)

ไฟล์ประกาศหลักเกณฑ์คณะฯ พ.ศ. 2568 **ไม่ใช่หน้าจอเพิ่ม** เป็นตารางคำนวณด้านหลัง

เมื่อเลือกเกณฑ์ในเป้าหมาย PA ช่อง **หน่วยภาระงาน** และ **คะแนนประเมินตนเอง** คำนวณอัตโนมัติตามสายวิชาการ

- Performance 80% ฐาน 1,820 หน่วย: ยุทธศาสตร์ 25% (455) + ภาระงานหลัก 55% (1,000) + มอบหมาย 15% (273) + เพื่อส่วนรวม 5% (92)
- Competency 20% จาก CC 7 ข้อ (รวม÷70)×20
- Dialog ประธาน: PA 80 + CC 20 = 100
- น้ำหนักข้อตกลงรวมต้องได้ 100 จึงขออนุมัติได้
- ส่งรายงานผลแล้วแก้ไม่ได้
- IDP ไม่เกิน 2 รายการ วิธีพัฒนา 70 / 20 / 10

เมื่อสถานะเป็นขออนุมัติ ปุ่มประธานอนุมัติ/ไม่อนุมัติโชว์ในฟอร์มเดียวกัน ไม่มีเมนูสลับบทบาท
