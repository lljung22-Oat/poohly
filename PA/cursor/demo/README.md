# เปิดโปรแกรมตรงนี้

ดับเบิลคลิก **`เปิดตรงนี้.html`** หรือเปิด `index.html`

อย่าใช้โฟลเดอร์ `.PA cursor` เพราะ Windows ซ่อนโฟลเดอร์ที่ขึ้นต้นด้วยจุด

บนเครื่องเปิดไฟล์ที่มองเห็นได้ ที่นี่

`C:\Users\poohl\appscript\PA\PA\cursor\demo\เปิดตรงนี้.html`

หรือ `C:\Users\poohl\appscript\PA\demo\เปิดตรงนี้.html`

หรือ `C:\Users\poohl\appscript\PA\เปิดตรงนี้.html`

ต้นฉบับที่ใส่ในโปรแกรมอยู่ที่โฟลเดอร์ `sources` ข้างไฟล์เปิดโปรแกรม

- `sources/คำอธิบายตัวชี้วัด-PA-2570-ฉบับจัดทำ-PA.pdf`
- `sources/แบบติดตามข้อมูลโครงการวิจัย-ปี-2570.xlsx`

เข้าสู่ระบบอาจารย์แล้วที่หน้าหลักมีสองการ์ดนี้

- คำอธิบายตัวชี้วัด PA 2570
- แบบติดตามข้อมูลโครงการวิจัย ปี 2570

## เข้าสู่ระบบ

หน้าแรกเลือกเฉพาะ **เจ้าหน้าที่** หรือ **อาจารย์** แล้วใส่ชื่อผู้ใช้ / รหัสผ่าน

- อาจารย์: `porntipa.c` / `123456`
- เจ้าหน้าที่: `staff.sh` / `123456`
- ผู้ดูแล (ช่องทางพิเศษ): `admin.mu` / `Admin#2570`

ผู้ประเมินเข้าได้เมื่อผู้ดูแลสร้างบัญชีให้แล้วเท่านั้น ข้อมูลทั้งหมดเก็บในฐานข้อมูล IndexedDB ของเบราว์เซอร์
