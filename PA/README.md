# เดโม PMS — คณะสังคมศาสตร์และมนุษยศาสตร์

วางไว้ให้ตรงกับโฟลเดอร์ `appscript/PA/demo` บนเครื่อง

## เปิดโปรแกรม

เปิดไฟล์นี้ในเบราว์เซอร์:

`PA/demo/index.html`

หรือจากโฟลเดอร์นี้:

```bash
python3 -m http.server 8765 --directory demo
```

แล้วไปที่ `http://localhost:8765/`

เลือกโหมดที่หน้าเข้าสู่ระบบ (อาจารย์ / สายสนับสนุน / กรรมการ / ประธาน / ฝ่ายบุคคลากร / Admin)
ปีงบประมาณเริ่มต้น 2570 เลือก 2569 ได้

## ไฟล์ในชุดนี้

- `demo/` — โปรแกรม PMS 9 โมดูล
- `manual-html/` — สรุปคู่มือ UM-01 / UM-03 / PMS (PMS1+PMS2 รวมแล้ว)
- `pms-demo.zip` — แพ็กโปรแกรมไว้ copy ทั้งโฟลเดอร์
