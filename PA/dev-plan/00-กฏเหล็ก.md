# กฎเหล็ก — ยืดหยุ่นตามต้นฉบับ ห้ามคิดเอง

## ความหมายของ “ยืดหยุ่น อย่าเคร่งครัด”

- **ยืดหยุ่น** = ทำตามที่เอกสารเขียน และเปิดทางเมื่อเอกสารไม่ห้าม ไม่ใส่ validation เกินต้นฉบับ
- **อย่าเคร่งครัด** = ห้ามบังคับช่อง ลำดับ ปุ่ม หรือสูตรที่ไม่มีในไฟล์ต้นทาง
- **ห้ามคิดเอง** = ถ้าไม่มีใน Word / PDF / สไลด์ / คำสั่งเจ้าของงาน ให้ทำหนึ่งในสองอย่างเท่านั้น: (ก) เว้นว่างไว้ให้กรอกอิสระ หรือ (ข) ทำเครื่องหมาย `SOURCE_MISSING` แล้วหยุด ไม่เดา

ตัวอย่างที่ถูก

- คู่มือบอกน้ำหนักรวมภาระงานต้อง 100 → ตรวจได้ แต่ถ้ายังไม่ครบให้บันทึกฉบับร่างได้ (PMS มีปุ่มบันทึกฉบับร่าง)
- คู่มือบอกส่งแล้วแก้ไม่ได้ → ล็อกหลังส่งเท่านั้น ไม่ล็อกตอนร่าง
- จุดเด่น / ข้อควรพัฒนา ใน UM-01 **ไม่บังคับ** ตอนให้คะแนน → อย่าบังคับกรอก

ตัวอย่างที่ผิด

- ประดิษฐ์เมนู ระดับคะแนน หรือคอลัมน์ที่ไม่มีในแบบ 05–09 / SHPA / ประกาศ
- รวมฟอร์มสายสนับสนุนกับสายวิชาการเป็นตารางเดียว
- ใส่แบบคำมั่น 11 ในวงจรหลักทั้งที่เจ้าของงานสั่งเอาออกจากเดโม (ไฟล์ยังต้องอยู่ในบัญชีเอกสาร แต่ไม่เปิดเป็นเมนูถ้าไม่ได้สั่งใหม่)

## แหล่งความจริง เรียงลำดับใช้

1. ไฟล์ Word/PDF ในโฟลเดอร์ที่เจ้าของงานชี้ (ชื่อไฟล์ตามบัญชี)
2. คู่มือ UM-01 V03 และ UM-03 V01
3. คำแนะนำระบบ PMS1 + PMS2 (ชุดเดียวกัน)
4. คำสั่งเจ้าของงานที่ขัดกับคำในสไลด์ **เฉพาะป้ายบนจอ** เช่น กรรมการ→หัวหน้างานขั้นต้น ประธาน→หัวหน้างาน
5. เดโมที่มีอยู่ใช้เป็นโครงจอ ไม่ใช้เป็นแหล่งเกณฑ์

เมื่อเอกสารสองชุดพูดคนละอย่าง ให้เก็บทั้งสองค่าใน config แล้วเลือกตาม `track` หรือตาม `labelMap` ห้ามเลือกข้างหนึ่งแล้วลบทิ้งอีกข้าง

## สองสายห้ามปน

| ชุด | ผู้ใช้หลัก | อย่าทำ |
| --- | --- | --- |
| รูปที่ 1 PA บุคคลากร | เจ้าหน้าที่สายสนับสนุน / บุคลากรตามแบบ 05–09 | อย่าใส่ตารางหน่วย 1,820 หรือ SHPA |
| รูปที่ 2 อาจารย์ | สายวิชาการ | อย่าใส่แบบ 05 06 07 08 09 11 ของสายสนับสนุน |

หน้าหลักของแต่ละคนโชว์เฉพาะการ์ดและวงจรของสายตนเอง

## สิ่งที่ยังไม่มีไฟล์ในเครื่องนี้

ชุด Word 05–11 และชุด SHPA **ยังไม่อยู่ใน VM** ตอนเขียนแผนนี้ มีแค่ภาพรายชื่อไฟล์  
ช่องในแบบ 05–09 และ rubrics สายสนับสนุน **ห้ามเดาตัวเลข** จนกว่าจะอัปโหลดต้นฉบับแล้วคัดทีละช่อง
