# แผนพัฒนาระบบประเมินผลการปฏิบัติงาน — ชุดอ่านก่อนลงมือ

ใช้ชุดนี้เมื่อจะเขียนโปรแกรมต่อ **ห้ามออกแบบฟอร์มใหม่** และ **ห้ามคิดเกณฑ์เอง**  
ตอนนี้ยังไม่ลงมือเขียนแกนโปรแกรม

## สแตกที่ล็อกแล้ว — ห้ามคิดสแตกอื่น และห้ามทำขนาน

โปรแกรมจริงสร้างตามชุดนี้เท่านั้น

| ชั้น | ที่ล็อกใช้สร้าง | หน้าที่ |
| --- | --- | --- |
| Frontend | React + HTML/CSS + Tailwind CSS | ส่วนติดต่อผู้ใช้ การจัดการสถานะบนจอ การเรียกบริการไปยังส่วนบริการ |
| Backend | Node.js (Express) ค่า `stack.backend.chosen` = `Express` | ส่วนบริการแบบ REST และ/หรือ GraphQL ตรรกะธุรกิจ การพิสูจน์ตัวตนด้วย JWT |
| Database | MySQL | โครงสร้างข้อมูลและการบันทึก แก้ไข ลบ เรียกดู |

Python (FastAPI) และ C# (.NET) อยู่ในเอกสารเป็นทางเลือกที่อนุญาตในบัญชีเท่านั้น **ห้ามสร้างคู่ขนาน**  
ค่าใน `pa-config.example.json` คือ `stack.backend.chosen` = `Express`

กติกาเดิมยังบังคับ: จัดทำตามเอกสารต้นฉบับ ห้ามคิดเกณฑ์เอง แต่ละบทบาทเห็นเฉพาะหน้าที่ของตน แยกสายวิชาการกับสายสนับสนุน
