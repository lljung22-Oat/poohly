ทดลองใช้งาน PA ล่วงหน้า

ไฟล์ทดลองแบบ standalone — เปิดหน้านี้ในเบราว์เซอร์แล้วเริ่มใช้งานได้ทันที ไม่ต้องติดตั้ง ไม่ต้องเปิด localhost และไม่มีลิงก์ไปส่วนอื่นของระบบ

เดโมนี้แยกจากระบบจริง ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่เปิดไฟล์เท่านั้น ตัวเลือกและอัตราคำนวณในเดโมเป็นตัวอย่าง โปรดตรวจสอบกับเกณฑ์ PA ฉบับจริงก่อนใช้งาน

ข้อจำกัดด้านความปลอดภัย: HTML ที่ส่งให้ผู้ทดลองเป็นไฟล์ฝั่งเครื่อง จึงไม่สามารถป้องกันการเปิดดูหรือคัดลอก source code ได้อย่างแท้จริง ปุ่มเมนู/ลิงก์ไปหน้าอื่นไม่มีในไฟล์นี้; การซ่อนเมนูหรือปิดคลิกขวาทำได้เพียงลดการเผลอกด ไม่ใช่การป้องกันโค้ด
